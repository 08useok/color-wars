# 플래티넘 모션

남성·39세·귀금속 도금 기술자. 최신 외형은 `../platinum-concepts/platinum-forms-1-2-face-v8.png`.

- 1진: 둥근 백금색 머리, 눈 두 개·작은 입, 회색 작업 셔츠·짧은 작업 바지.
- 2진: 인간형 얼굴·백금색 머리·보호면·작업복·휴대 도금 장비.
- 각 형태: 걷기 4장, 공격 6장, 피격 1장, 복귀 1장. 총 24포즈.
- 공격: 도금 브러시를 들어 왼쪽으로 뻗으며 은청색 도금 분사를 내고 복귀.
- `platinum_1.webp`, `platinum_2.webp`: 1024×768 RGBA 시트, 256×256 고정 셀.
- `atlases.json`, `platinum-motion-atlases.js`: 프레임 좌표. 아직 게임에서 로드하지 않음.
- `../../work/platinum-motion/preview.html`: 상태 선택형 재생 미리보기.
- 같은 폴더의 `platinum_1-profile.webp`, `platinum_2-profile.webp`: 첫 걷기 포즈.
- `../../scripts/pack-platinum-motion.py`: 생성된 그림을 자르기·크기 조정·정렬·패킹만 함. 발 기준선 y=240.

## 생성 지시와 참고

내장 image_gen 사용. `platinum-forms-1-2-face-v8.png`를 인물·복장 참고로 사용했다. 1진 얼굴은 이전 확정 외형의 머리만 편집해 검은 타원 눈 두 개와 작은 곡선 입을 추가하고, 회색 작업복과 2진을 유지했다.

각 형태를 별도로 투명 배경 4열×3행, 12개 전신 포즈로 생성했다. 첫 행은 좌우 다리를 번갈아 내딛는 걷기 4장, 둘째 행은 준비·브러시 들기·분사·최대 분사의 공격 4장, 셋째 행은 공격 마무리·준비 자세 복귀·피격·회복이다. 동일한 크기와 왼쪽 3/4 방향, 굵은 외곽선과 단순 음영, 눈 두 개와 입, 작은 몸통·짧은 팔다리, 도금 브러시·금속 시편을 유지하도록 지시했다. 1진은 구체 머리·회색 셔츠, 2진은 백금 머리카락·인간형 얼굴·보호면·전원 장비를 고정했다. 포즈 사이 투명 여백·효과 잘림 금지·문자 없음 조건을 넣었다.

외형·모션만 제작했으며 능력치·희귀도·획득 방식·실제 게임 연결은 미구현이다.
