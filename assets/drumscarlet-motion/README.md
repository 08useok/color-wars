# 군악 스칼렛 모션 에셋

- 1진은 둥근 머리·작은 손·타원형 발과 작은 북. 2진은 단발·군악대 모자·제복과 허리 북.
- 24장. 각 형태는 걷기 4장·공격 4장·대기 2장·넉백 1장·복귀 1장이다.
- 투명 WebP 시트 (1280×864, 셀 320×288), 프로필, 좌표 JSON 및 DRUMSCARLET_MOTION_ATLASES 상수 JS 포함.
- 내장 이미지 생성으로 원화를 만들고 자르기·크기 조정·정렬만 코드로 처리했다. 프롬프트는 이 폴더에 보관했다.
- 원화: reference-sheets/drumscarlet-motion/. 패킹: scripts/pack-drumscarlet-motion.py.
- 미리보기: work/drumscarlet-motion/preview.html. GIF·확인용 시트·audit.json 포함.
- `allies-71-motion.js`로 게임 전투·도감에 연결했다. 아종은 기존 선딜 0.3초에 맞췄고, 아이보리는 기존 즉시 타격에 맞춰 충돌 장면부터 재생한다. 아종의 능력치는 유지했다. 아이보리 3진은 기존 라이트 크림 명의의 초안을 아이보리로 대상 정정했다.
