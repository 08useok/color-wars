# 7.3.0 연결·검증

로컬 버전은 7.3.0이다. 이번 작업으로 신캐 3명·신규 3진 2명·구레전드 41~49장·신규 사이클론·보어 릴레이를 게임에 연결했다. 커밋·푸시는 하지 않았다.

## 연결된 콘텐츠

- 썬플라워·펀: 가든즈 울슈레 뽑기. 제이드: 워터즈 울슈레 뽑기. 1·2진별 전용 대기·걷기·공격·넉백과 프로필을 사용한다.
- 마스터 바이올렛·아키텍트 오키드: 기존 3진 해금·레벨·개다래 조건과 형태 선택/저장을 따른다. 공체는 각각 120%. 현재 파일에 정의된 바이올렛 둔화 65%·3.5초, 오키드 열파 20~56·2.4초·회당 60%를 유지했다.
- 구레전드: 49개 장·324개 맵, 고대 연구소까지. 별도 구레전드 추가 문서 참조.
- 긴급 폭풍 경보 / 진격의 폭풍 소용돌이: 세계편 3장 클리어 후 특별 스테이지. 허리케인 사이클론 원본 모션, HP 750,000·공격력 3,666·0.2초 간격·떠 있는 적·원작 타격 구간 250~650을 적용했다. 기본 XP 3,800, 신규 보상 캐릭터 없음.
- 보어 5종 릴레이: 세계편 3장 클리어 후 특별 스테이지. 샤이 보어 200% → 이노와르 100% → 천사 멧돼지 100% → 불칸 보어 150% → 좀비 보어 200%. 첫 주자는 10초, 다음 주자는 앞 주자를 완전히 처치한 2초 뒤 등장한다. 부활 대기 중인 좀비는 처치 완료가 아니다. 다섯 주자 처치 전에는 적 성이 체력 1에서 버틴다. 기본 XP 6,000.

새 이벤트는 기존 748개 맵 뒤 절대 번호 748·749에 붙였다. 기존 저장 번호·출현 규칙·능력치를 비교해 유지됨을 확인했다. 신캐/3진 모듈에서 다른 작업으로 변경된 능력치도 되돌리지 않았다.

## 검증

- `scripts/test-allies-73.cjs`: 시리즈·뽑기 등록, 가격, 썬플라워 앞뒤 타격·속성 제한, 펀 이동/약화, 제이드 맷집, 신규 3진 능력 검사 통과.
- `scripts/test-stages-73.cjs`: 기존 맵/능력치 보존, 해금, 원본 보스 수치·등장 시각, 사각지대, 순차 출현·2초 대기, 좀비 부활 중 성 보호, 완전 처치 후 성 보호 해제 검사 통과.
- 전투 시뮬레이션: 신규 두 맵 각각 시드 1·2·3·Lv.30·연구/보물 완성·smart2. 허리케인 38.23~49.10초, 릴레이 66.47~68.67초로 6판 모두 승리했다. 모든 계정·덱의 난이도 보증은 아니다.
- 별도 임시 브라우저: 버전 7.3.0·아군 119명·전용 3진 18명·맵 750개·구레전드 49장 초기화, 뽑기 풀, 신캐/3진 실제 스프라이트, 총평, 소유권·레벨·3진 보유·2진 선택의 재시작 복원 검사 통과.
- 브라우저 보상 처리 직접 호출 검사: 연구력 보정 포함 XP 9,500/15,000 지급, 결과 화면, 다음 맵 버튼 숨김, 두 이벤트 클리어 저장/재복원 확인. 이 검사는 실전 플레이 승리 검사와 구분한다.
- 8개 형태·128프레임·32개 GIF의 투명도·프레임 경계·걷기 4프레임 검사 통과.
- 티어표: 2진 119명·3진 18명, 총 137개 형태를 현재 코드로 1,500판 재측정. 황제의 야옹이 ★3·Lv.30·시드 3·auto/smart2. 짧은 재측정이며 특화 성능·인접 순위의 확정적인 서열은 아니다.
