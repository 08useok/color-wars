# 8.3.0 로컬 출시 준비

버전·공지까지 8.3.0으로 준비했다. 아직 커밋·푸시·배포하지 않았다.

- 기본 8명 3진: 전용 그림 192장, 30FPS 모션, 공체 2배, 승인된 능력, 도감 총평·형태 선택 연결.
- 단죄천사 쿠오리넬 강림: 원본 파츠·모션, 미래편 1장 이후 해금, 슈퍼 레어 행진 옐로 30% 보상.

- 공지 콘텐츠 범위를 신레전드 0~18장으로 갱신했다.

### 끈적끈적 샤워 ★4 확인 덱

탐사 민트시안·라이트 크림·베이비 블루·클로버·퓨전 크림·마젠타·가넷·라피스·실버·모스. 전부 레어·EX다. Lv.40·auto에서 407.53 / 470.33 / 531.37초 승리. Lv.50에서는 281.37 / 290.70 / 282.37초 승리했다.

이 맵에서는 높은 배율의 스타 에이리언과 베리어에 막히는 양상이 나왔다. Lv.30 결과만으로 버그나 클리어 불가능으로 판단하지 않고, 수치를 유지한 채 고레벨 합법 덱으로 재검수했다.
