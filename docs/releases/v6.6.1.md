# v6.6.1 — 출시 준비 잠금과 역할별 평가

- 전용 3진 모션이 없거나 걷기·공격·피격 정보가 불완전하면 진화와 3진 능력 적용을 잠그고 ‘곧 출시 예정’을 표시한다. 기존 진화 기록과 재료는 보존한다. 핫 핑크 자동 진화도 같은 조건을 적용한다.
- 도감 평가는 과거 단일 맵 단축 시간을 좋다/나쁘다로 변환하던 방식 대신, 총평과 현재 능력을 바탕으로 고방·탱커·딜탱·딜러·메즈 지원 역할, 장점, 주의점, 편성법을 설명한다. 평가에 티어나 희귀도 등급을 붙이지 않는다. 기존 티어표 문서는 별도 분석 자료로 유지한다.
- 1·2·3진은 해당 형태의 현재 수치로 설명하며, 미공개 능력은 기존 숨김 규칙을 유지한다. 전투 능력치는 이번 평가 문구 변경으로 수정하지 않는다.
- 사각 없는 라즈베리 3진에 사각 보호가 필요하다고 나오던 비교 문구를 수정한다.
- 머리말 버전·공지·파일 캐시 갱신을 v6.6.1에 맞춘다.

생성: `node scripts/make-codex-verdict.cjs`. 역할 평가 공통 함수는 `scripts/lib/ally-role-assessment.cjs`이며 도감과 시험 도구 총평이 공유한다. 과거 점수 분포를 재측정한 업데이트가 아니다.

검증: `scripts/role-verdict-browser-test.cjs`에서 106명·221개 형태별 평가의 등급 표현 제거, 대표 역할, 3진 구분, 실제 도감 표시, 숨김 조건, 능력치 불변, v6.6.1 버전 표기 통과. 3진 에셋 잠금·저장 보존은 `scripts/true-form-asset-gate-browser-test.cjs`로 검증한다.
