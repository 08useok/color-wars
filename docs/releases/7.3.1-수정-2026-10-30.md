# 7.3.1 수정·검증

7.3.0 점검에서 두 문제를 재현하고 수정했다. 기존 캐릭터 능력치·가격·맵 배율은 변경하지 않았다. 로컬 버전은 7.3.1이며 커밋·푸시는 하지 않았다.

## 수정

1. **좀비 보어 땅굴의 릴레이 처치 오인**
   - 땅굴 처리 모듈은 전투 계산 중 지하의 적을 `game.units`에서 잠시 제외한다. 릴레이가 이 순간을 처치로 오인해 다섯 주자 완료로 넘어가며 성 보호를 해제할 수 있었다.
   - 현재 주자의 실제 객체를 전투 상태에 보관해 생존·부활 상태를 추적한다. 땅굴 중에도 체력이 남아 있으면 다음 주자로 넘어가지 않는다. 새 전투의 `reset()`은 이 참조도 초기화한다.
2. **새로고침 후 이벤트 재도전 XP 오계산**
   - 허리케인·릴레이의 별도 완료 기록은 복원되지만, 코어 진행 로더는 스토리 스테이지만 남겼다. `awardXP()`가 보는 `cleared`에는 완료 기록이 없어 첫 클리어 XP를 다시 지급했다.
   - 두 이벤트의 확인된 완료 기록만 메모리의 XP 이력에 중복 없이 복원한다. 복원만으로 XP를 지급하거나 저장 내용을 다시 쓰지 않는다. 완료 기록이 없는 계정은 첫 클리어 보상을 유지한다.

## 재현·검증

- 수정 전 회귀 검사: 지하 좀비가 있을 때 릴레이 주자가 4→5로 넘어가며 실패했다. 수정 후 수동 제외 상황과 실제 땅굴 업데이트 모두 주자 4·성 체력 1을 유지했다.
- 부활 대기 중에는 종료되지 않고, 좀비 킬러의 완전 처치 뒤에는 정상적으로 성 보호가 해제된다.
- 수정 전 브라우저: 완료 표시가 있는 계정에서 새로고침 후 XP가 3,800/6,000으로 지급됐다. 수정 후에는 재도전 기준 1,900/3,000으로 지급된다(연구 보정 없는 테스트 계정).
- 복원 과정의 XP·원본 진행 저장값 불변, 반복 로딩 시 중복 없음, 완료 기록 없는 계정의 3,800/6,000 XP 유지도 확인했다. 실제 사용자 저장이 아닌 별도 임시 브라우저 계정으로 검사했다.
- 신규 두 맵 각각 시드 1·2·3·Lv.30·보물/연구 완성·smart2, 총 6판 모두 승리했다. 허리케인은 38.23~49.10초로 유지, 릴레이는 88.60~91.23초였다. 이전의 약 66~69초 기록은 땅굴 처치 오인의 영향을 받았으므로 이번 패치 성능과 직접 비교하지 않는다.
- 황제의 야옹이 ★3 기준 덱·시드 3·auto/smart2, 총 6개 결과가 기존 티어 측정 원본과 정확히 같았다. 전체 1,500판 재측정은 반복하지 않았다.
