# 기존 이미지 기반 클로버 3진·독립 아종 적용

사용자가 제공한 기획표를 기준으로 구현했다. 동기화된 sources는 수정하지 않았다.

확정 3진 이름: 어부 살몬·부자 골드·바느질 베이지·럭키 클로버. 화이트·레드·탄 아종은 모두 여성형이다. 기존 원본 외형을 유지하며 설명에 설정을 반영한다.

추가 수정: 골드·베이지는 이름만 적용돼 있던 누락을 수정했다. 부자 골드는 HP 1.3배·공격 1.5배·5연타 및 금괴 파편 5개·처치 돈 보너스 +150%, 바느질 베이지는 HP 1.3배·공격 1.4배·사거리 14·검은 적 정지 60%/3초·관통 2명이다. 실제 개다래 진화, 재료/XP 차감, 중복 진화 차단, 재접속 후 골드·베이지·클로버 3진 유지까지 검증했다. 골드·베이지 전용 3진 이미지 원본은 현재 확보되지 않아 기존 2진 외형과 3진 표시를 사용한다. 이 두 외형 작업은 미완료다.

HP·DPS는 콤보·+레벨·치명타·표식 보너스를 제외한다. 1장 가격은 기존 엔진 규칙대로 2/3이다. 1진은 기존 레벨 성장과 2진 HP·공격 1.15배 규칙을 사용한다. Lv.10 이후 2진 선택이 가능하다.

- 화이트: 범위, 약화 발동 50%·공격력 50% 감소·4초, 둔화 발동 30%·3초. 둔화 속도는 기존 엔진의 0.5를 사용한다.
- 레드: 범위, 표식 발동 60%·5초·받는 피해 1.3배. 적용 타격 다음부터 증폭하며 재적용은 시간 갱신, 배율 중첩 없음. 바리어에 막힌 타격은 표식을 적용하지 않고 메탈의 비치명타 피해 1 규칙을 유지한다. HP 바와 표식 문구로 표시한다.
- 탄: 공격 시작 0.4초 후 첫 발, 0.16초 간격으로 6발. 각 발 치명타 20%·2배, 넉백 20%·거리 8. 사용자 최신 표에 없는 천사 초데미지는 추가하지 않았다.
- 클로버 3진: 2진 대비 HP 1.3배·공격 1.5배, 3회 공격, 치명타 25%, 검은 적 약화 발동 80%. 기존 초록 열매 2·씨앗 4·60,000 XP 진화 비용을 유지한다.

사거리와 화이트 약화 확률은 기존 `신규-3진-아종-스펙-2026-10-10.md`의 값을 사용했다. 공격 주기, 정확한 공격력, 탄 넉백 확률·간격은 이번 기획의 대략적 DPS를 구현하기 위해 정한 값이다. 목표 순위는 기획 목표이며 실측 순위가 아니다.

획득: 화이트·레드·탄 강림 각 극난도(30%) → 초극난도(100%). 세계편 2장 달 클리어로 첫 단계, 해당 극난도 클리어로 두 번째 단계가 열린다. EX 독립 캐릭터이며 뽑기 풀에 넣지 않았다. 이미 획득한 캐릭터는 중복 지급하지 않는다. 기존 스테이지 558개 뒤에 6개를 추가해 기존 저장 번호를 보존한다. 별도 강림 클리어 저장 키는 `red-battle-subspecies-v1`이다.

원본 21장과 무손실 7장 시트·ZIP은 `exports/clover-variants/`에 보존한다. 게임용 아틀라스도 원본 RGBA 픽셀을 유지하며 생성형 이미지 도구를 사용하지 않았다.
