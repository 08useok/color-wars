짧게 스프라이트 잔여 버그 1건만 수정한 하루.

## 오렌지 2진 예비동작 프레임 버그 수정
- windup(예비동작) 프레임에서는 팔이 아직 내려간 대기 자세인데, 과즙 스플래시 그림이 이미 뺨 옆에 떠 있어 주먹과 무관하게 얼굴에서 뿜어나오는 것처럼 보이던 문제
- 해당 프레임에서 캐릭터 실루엣과 분리된 스플래시 영역만 알파를 지워 제거, 같은 칸 맨 위(y=0)에 남아있던 원본 잔여 픽셀도 함께 정리
- 다른 프레임(걷기/임팩트/회복/피격)과 다른 캐릭터는 변경 없음

## 검증 방식
브라우저에서 해당 프레임을 직접 재생해 스플래시가 얼굴에서 분리돼 있지 않은지 확인.
