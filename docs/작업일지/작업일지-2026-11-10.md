# 작업일지 - 2026-11-10

## 8.4.0 대포 교체와 좀비 원작 모션

- 기지 강화에서 기본·천둥·슬로우·브레이크·천사포를 선택하고 저장한다. 전투 중 교체는 잠근다.
- 원작 파츠·리그로 만든 대포 발사 이펙트를 30FPS로 연결했다. 대포 본체는 유지한다.
- 색조 필터로 대신하던 좀비 9종을 전용 원작 걷기·공격·넉백으로 교체했다. 기존 전용 시트 3종을 재사용하고 6종을 확보했다. 적 수치·스테이지·출현표는 변경하지 않았다.
- 오늘 선택한 대포의 동적 이펙트를 이미지 준비 목록에 추가했다. 교체 시 준비가 끝날 때까지 출격을 막고 이전 발사 연출을 제거한다. 브레이크포는 두 시트를 모두 준비한다.
- 공지와 표시 버전을 8.4.0으로 올리고 HTML의 변경 스크립트 캐시 번호를 갱신했다. 신규 레어 3종 초안은 이번 출시에서 제외했다.

## 확인

- 대포 전투 효과·저장·전투 중 교체 잠금 검사 통과.
- 대포 이펙트 재생·일시정지·종료·교체 정리 검사 통과.
- 좀비 9종 모션 및 전체 적 수치·스테이지·출현표 불변 검사 통과.
- 우주편 2장 초기 저장 경합·장별 백업·등록 검사 통과. 등록 검사의 빅뱅 전투는 제한 시간 내 클리어하지 못했으며, 클리어 검증으로 취급하지 않는다.
- 브라우저에서 대포 5종 모두 선택한 시트의 사전 로딩·발사·교체 정리를 확인했다. 좀비 9종의 이미지가 모두 로드됐으며 색조 필터와 실행 오류는 없었다. 사용자 저장 데이터는 읽거나 변경하지 않았다.
- 전체 스테이지 재측정은 하지 않았다.

기존 다른 작업의 변경 파일은 이번 커밋에서 제외한다.
