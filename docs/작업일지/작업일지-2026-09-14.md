## 3. 프로필 카드 다듬기
- 카드 아래 box-shadow 제거(이미지 자체 테두리와 겹쳐 두꺼워 보이던 문제)
- 테두리를 `border`→`outline`으로 변경: `border`는 배경 위에 그려져 캐릭터마다 그림이 셀 경계에 닿는 정도가 달라 안 보이거나 흰 여백이 비치던 문제였는데, `outline`은 박스 바깥에 그려져 항상 동일하게 보임
- 캔버스로 `profile_sheet.png` 각 셀의 실제 캐릭터 바운딩 박스를 픽셀 단위로 측정해 8명 전부 동일 비율로 보이도록 유닛별 `background-size/position`을 하드코딩(`PROFILE_CALIB`). 이 과정에서 브라우저가 이전 `game.js`를 강하게 캐싱하는 문제를 겪어 `style.css`/`game.js`에 `?v=` 캐시버스팅 쿼리를 추가(이후 두 파일 수정 시마다 버전 숫자를 올려야 함)

## 4. 2진 진화 전투 스프라이트를 실제 아트로 교체
- 사용자가 8색 각각 걷기/공격/피격 프레임이 담긴 스프라이트 시트(체커보드 배경, 실제 알파 없음)를 전달
- 이미지 테두리에서 flood-fill로 연결된 밝은 영역만 배경으로 판정해 투명화(캐릭터 내부 흰색 하이라이트는 보존), 256색 팔레트로 압축(2.66MB → 179KB, `assets/evolved_sheet.png`)
- 기존 CSS 막대인간(`.evolved-stick`)을 이 시트 기반 `.evolved-sprite` 이미지로 교체, 핑크는 아트에 리본이 이미 포함돼 있어 기존 `.pink-ribbon` 오버레이와 중복 표시되지 않도록 조건 수정

## 5. 스폰/덱 구조 개선

## 6. 스프라이트 좌표 버그 수정
- 초기 커밋 때부터 어떤 요소도 쓰지 않던 죽은 `.face` CSS 규칙이 최종 보스 유닛 타입명("face")과 우연히 충돌해 `top:4px`가 `.unit`의 `bottom:15%`를 덮어써 대갈이군이 하늘에 뜬 채로 렌더링되던 문제 수정
- 곰선생(`bear`)·빠옹(`leboin`) 스프라이트 시트 좌표를 재측정해 걷기/공격/피격 프레임이 다리 잘림·얼굴 클로즈업 등 잘못된 영역을 가리키던 문제 수정

## 7. HUD 개편 및 반응형 스케일
- 상단 HUD 가운데 몰려 있던 적/아군 성 체력 표시를 각 성 바로 위 배지(`.base-hp`)로 이동, 상단에는 돈 표시만 남김
- 화면 폭에 따라 `--sprite-scale` CSS 변수(0.65~1.35배)로 유닛 스프라이트 크기를 조절하는 반응형 로직 반영

## 8. 공격 애니메이션·투사체 절단 버그 수정
- 원인: `ally_atlas.png`(+시안 전용 시트)의 "투척" 그림이 그리드 셀 2칸(col3~col4)에 걸쳐 그려져 있는데, 기존 코드가 매 프레임 1칸만 잘라 보여줘서 애니메이션 도중 투사체가 셀 경계에서 반으로 잘려 보이던 문제
- 오렌지/옐로우/시안/퍼플: "임팩트" 구간(col4)에서 2칸을 한 번에 보여주고, 직전 "준비" 구간은 깨끗한 col2로 대체
- 그린: 같은 방식을 적용했다가 오히려 어색해짐 — 그린은 다른 아군과 달리 col3(부메랑을 든 자세)/col4(던진 자세)가 정상적인 2단계 동작이었음을 확인하고 원래의 "들기→던지기" 연출로 되돌림
- 핑크 리본이 머리에서 분리돼 떠 보이는 문제를 4차례에 걸쳐 미세 조정: 정적 프레임 기준값(53px)에서 시작해, 걷기 애니메이션 전 구간·보스 넉백(`.boss-knocked`, 회전 규칙이 누락돼 있었음)까지 재생시켜 확인하며 최종 30px까지 낮춤
