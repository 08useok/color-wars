# 작업일지 - 2026-10-01

대상 프로젝트: `red-battle-doge.html` ("레드 · 세계편" - 냥코 대전쟁 클론)

피격 번쩍임·2진 걷기 모션 등 시각 버그를 정리하고, 전투 하단 UI와 치명타 연출을 추가한 하루.

## 1. 피격 번쩍임 수정 (메탈 하마양)
- 메탈 하마양 피격 시 번쩍임으로 밝기를 1.2배 올리자 철판 회색(200)이 거의 흰색이 되어 날아가던 문제 발생
- 밝기 대신 흰 외곽 발광 방식으로 변경해 철판 색이 유지되도록 수정
- 같은 방식을 엑토낼름이에도 시도했으나 어색해서 기존 밝기 번쩍임으로 복구(발광 방식은 메탈 하마양에만 적용)

## 2. 2진 스프라이트 버그
- 크리스탈·라벤더 2진 피격 프레임이 반대를 보던 문제를 프레임별 `flip` 값을 추가해 좌우 반전
- 레드·그린·시안 2진 걷기 모션에서 무기(검·부메랑·물방울)가 깜빡이던 문제 → 무기가 보이는 프레임만 쓰도록 고정
- 그린·시안은 그 과정에서 걷기 다리 동작이 사라져 다시 복원: 들고 있는 부메랑/물방울을 1번 프레임에서 잘라내 각 프레임의 손 위치로 재배치해 전신 정지 없이 계속 들고 있게 함

## 3. 전투 하단 UI 개편
- 수입 업그레이드를 세로 2칸 전용 버튼으로 분리, 캐릭터 버튼은 2줄×5개 배치

## 4. 크림슨·라즈베리 치명타 + 치명타 연출
- 크림슨(급소에 꽂히는 강타)·라즈베리(초장거리 급소 저격)에 10% 확률 2배 치명타 추가, 버튼/도감 치명타 아이콘·프로필 설명·메탈 하마양 도감 문구 갱신
- 치명타 이펙트 신규: 섬광·별 폭발·충격링·불꽃 8개·"CRITICAL!" 팝업·짧은 화면 흔들림. 대상 위치의 전장에 그려서 대상이 쓰러져도 이펙트는 끝까지 재생되며, 움직임 줄이기 설정 시 흔들림·불꽃은 생략
