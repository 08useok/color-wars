# 작업일지 - 2026-10-21

대상 프로젝트: `red-battle-doge.html` ("레드 · 세계편" - 냥코 대전쟁 클론)

초보자 플레이 시험을 하고, 그 결과로 위키에 "초보자 공략" 탭을 만든 하루. 시험 도구 결과를 실제 사이트에서 다시 확인하며 여러 번 정정함.

## 1. 초보자 세계편 1장 시험과 정정
- 새 계정 튜토리얼·한국 실제 플레이, 시험 도구로 48스테이지를 돌림. 처음 결론은 "XP를 안 쓰면 중국에서, 덱 세팅을 안 하면 뉴욕에서 막힘, 수입 업그레이드를 안 누르면 달이 2배"
- 정정 1: smart 출격이 수입부터 올려 레드 Lv.1이 지던 시험 오류. 자동 출격 포함 재측정하니 레벨 1로도 마다가스카르까지 깨고 남아프리카부터 Lv.4~5 필요
- 사이트 확인: Lv.1로 태국~마다가스카르 클리어, 남아프리카는 Lv.1 패·Lv.2 2승3패·Lv.3 3승1패·Lv.4 5승, 새 아군은 덱에 자동으로 안 들어감
- 정정 2: 사이트에서 레드만으로 뉴욕 3번 모두 클리어. 실제 막힘은 할리우드(45번째, 892초에도 적 성 9,942/20,000 교착)이고 "뉴욕에서 막힘"은 도구 오류. 전 아군 덱으로 할리우드~달 클리어(1장 48/48), 알래스카는 자동 출격이 방어 없이 수입부터 올려 12초 패·사람 방식은 77초 승

## 2. 위키 "초보자 공략" 탭
- 구조안: 레드로 시작 → 레벨업 → 덱 세팅 → 막힘 점검 흐름의 7장 목차와 막혔을 때 점검표, 스테이지 카드 팁
- 위키 맨 앞 탭으로 세계편 1장 7개 장·점검표를 구현하고 스테이지 탭에 한 줄 팁 추가. 처음 접속하면 공지·스테이지 선택 없이 바로 한국 튜토리얼 전투로 시작(버전은 올리지 않음)
- 범위를 순서대로 확장하며 사이트에서 직접 확인: 세계편 2장(8~10장, 48스테이지 전승·확정권 보상·오닉스·Lv.20)과 뽑기(11~15장, 60회 확인), 2장 추천 덱(기본 캐릭터만: 레드·옐로우·오렌지 + 샤르트뢰즈·라즈베리·살몬·골드·아이보리·애저·블루, 단독 효과 순위 10명 덱은 달 0/4 패라 방어 필수), 세계편 3장(17~19장, 레어 14명 해금 확인, 3장 달 보상), 미래편(20~21장)·우주편 1장(22장)·레전드 ★1(23~24장)
- 21장 "미래편 추천 아군": 처음에는 시험 도구 600초 제한 때문에 부유대륙만 막히는 것으로 나왔으나, 사이트에서 추천 덱(전원 Lv.20)으로 미래편 9곳을 직접 깬 결과로 교체하고 "막히는 스테이지"를 삭제(실제 10명 덱은 부유대륙 68초에 깸)
