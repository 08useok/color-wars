# 작업일지 - 2026-09-17

대상 프로젝트: `red-battle-doge.html` ("레드 · 세계편" - 냥코 대전쟁 클론)

신규 아군 10명의 남은 스프라이트 교체를 마무리하고, 밸런스·해금 구조를 정비한 뒤 2진 진화 좌우 반전 버그와 상태이상 아이콘을 추가한 하루.

## 1. 나머지 신규 아군 7명 스프라이트를 새 원화로 교체
- 샤르트뢰즈·민트·애저·크리스탈·라벤더·살몬·라즈베리를 사용자가 제공한 새 원화(`unit<이름>_ally-sprite.png`, 8열 단일행: 걷기 3+공격 3+피격 1)로 교체
- 이번 원화들은 이미 투명 배경이 적용돼 있어 별도 디매팅 없이 알파 채널 분석만으로 크롭 좌표 산출
- 투사체(콩알탄/아이스크림/향수구름/낚싯줄/크리스탈/서핑 파도/저격 총구화염)가 칸 경계를 넘어 그려진 캐릭터는 크림슨·골드·아이보리와 동일하게 임팩트 프레임을 넓은 크롭으로 처리

## 2. 신규 아군 훈련 화면 프로필 사진 버그 수정
- `new_chars_profiles.png`의 5x2 그리드가 캔버스를 정확히 반으로 나누지 않고 위아래 큰 여백을 둔 채 중앙 띠에만 그려져 있어, 균등 분할을 가정한 기존 코드가 여백+그림 상단 절반만 보여주던 문제
- 기존 8명(`PROFILE_CALIB`)과 동일하게 캐릭터별 실측 좌표 기반 픽셀 단위 캘리브레이션(`NEW_PROFILE_CALIB`)으로 교체

## 3. 신규 아군 10명 해금 조건을 세계편 2장 클리어로 전환
- 기존에는 자금만 있으면 언제든 뽑을 수 있었으나, 오렌지~핑크와 동일하게 스테이지 클리어 해금 방식으로 전환
- 2장 중국~브라질 구간에 1명씩 고르게 배치: 중국(크림슨)·일본(골드)·인도(아이보리)·케냐(샤르트뢰즈)·사하라사막(민트)·러시아(애저)·스페인(크리스탈)·노르웨이(라벤더)·뉴욕(살몬)·브라질(라즈베리)
- 해금 안내 문구와 스테이지 클리어 시 뜨는 "OO 해금!" 메시지에도 반영

## 4. 밸런스: 적 재출현/첫 등장 시간 상한
- 일부 스테이지(케냐 280초 대기, 하와이 곰선생 160+266초 재출현 등)의 위키 원본 타이밍이 지나치게 길어 빠른 클리어 시 해당 적을 거의 못 보는 문제
- 재출현 간격은 두 값의 비율을 유지한 채 최댓값이 40초를 넘지 않도록 비례 축소, 첫 등장 시간은 120초로 단순 상한
- 시간이 아니라 진행도(성 체력 %, 1회성 카운트)에 달린 스폰은 이번 변경에서 제외. 2장 미러링 스테이지는 데이터를 그대로 복사하므로 자동 반영됨

## 5. 2진 진화 스프라이트 버그 수정
- 진화 유닛에서 1진 그림자 스프라이트(`.ally-shadow`)가 그대로 남아 겹쳐 보이던 문제: `.unit.evolved`가 `.ally-sprite`만 숨기고 그림자는 숨기지 않아, 애니메이션 함수가 진화 분기에서 일찍 반환되며 그림자의 `background-position`을 한 번도 갱신하지 않고 기본값(레드 1진 걷기 프레임)을 그대로 노출하고 있었음 → 그림자도 함께 숨기도록 수정
- 레드 2진(칼 든 형태)이 다른 캐릭터와 반대 방향을 보고 있어 좌우 반전 처리, 이어서 같은 스프라이트를 공유하는 나머지 7명(오렌지~핑크)에도 동일하게 적용
- 캐시 무효화를 위해 `game.js`/`style.css` 버전 쿼리 갱신(v7/5 → v8/6) — 실제로는 정상 동작하는데 구버전 캐시가 원인일 가능성을 배제하기 위한 조치

## 6. 빙결(정지) 상태 아이콘 추가
- CSS로 그린 금색 스톱워치 아이콘(`.freeze-icon`)을 민트 설명 문구와 빙결된 적 머리 위 배지(`.freeze-badge`)에 표시, `update()` 루프에서 매 프레임 `.frozen` 클래스 토글로 노출 제어
- 이후 배치 조정: 문장 중간 인라인 삽입 대신 퍼플과 동일하게 "Lv.X" 옆으로 이동
- 사용자가 제공한 실제 금색 스톱워치 이미지(`assets/freeze_icon.png`)로 CSS 도형을 교체(배지 크기/위치 클래스는 유지)
- 둔화·약화·치명타·끌어오기 등 나머지 특수 능력 아이콘은 매핑이 확정되면 추후 추가 예정
