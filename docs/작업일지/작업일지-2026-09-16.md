대상 프로젝트: `red-battle-doge.html` ("레드 · 세계편" - 냥코 대전쟁 클론)

짧은 하루. 신규 아군 중 크림슨·골드·아이보리 3명의 스프라이트를 사용자가 새로 그려준 원화로 교체.

## 1. 크림슨 스프라이트를 새 원화로 교체
- 기존 `crimson_sheet.png` 대신 새로 제공된 8열 단일행 시트(`unitcrimson_ally-sprite.png`)를 사용하도록 변경
- 걷기/공격(예비동작·펀치·후속)/피격 크롭 좌표를 알파 채널 분석으로 새로 산출해 반영, 2진 진화 스프라이트는 변경 없음

## 2. 골드·아이보리 스프라이트를 새 원화로 교체
- 사용자가 제공한 새 원화(`Gold.png`, `ivory.png`)가 워터마크 미리보기용 체크무늬가 픽셀에 그대로 구워진 파일(알파 채널 없음)이라, 테두리 밖에서 배경까지 연결된 영역만 투명 처리하는 플러드필 알고리즘으로 체크무늬·워터마크를 제거하고 실제 투명 배경 시트를 복원
- 두 캐릭터 모두 예비동작 이후 투사체(금괴/아이스크림)가 캐릭터 칸 경계를 넘어 그려져 있어, 임팩트 프레임을 투사체+피격 표정을 함께 담는 넓은 크롭으로 처리(그린/오렌지 계열의 wide-throw 방식과 동일)
- 2진 진화 스프라이트는 이번에도 변경 없음

## 참고
크림슨의 교체본(`unitcrimson_ally-sprite.png`)은 코드에서 참조만 바뀌고 이미지 파일 자체는 아직 git에 커밋되지 않은 상태로 남아있음(기존 `crimson_sheet.png`도 작업 트리에서 삭제된 채 미반영). 다음 정리 때 함께 커밋 필요.

## 검증 방식
새로 만든 시트를 어두운 배경에 합성해 워터마크·체크무늬 잔여 없음을 확인하고, 브라우저에서 해당 캐릭터들의 걷기·공격 프레임을 직접 재생해 확인.
