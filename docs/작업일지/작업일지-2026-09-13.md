- 캐릭터 강화 Lv.10 도달 시 스틱맨 형태의 2진 스프라이트로 외형 변경
- 아군별 프로필 카드(설명 문구 + 진화 효과 텍스트) 추가
- 아군별 고유 진화 보너스: 레드(공격력 +20%), 오렌지(범위 +35%), 옐로우(체력 +25%), 그린(부메랑 귀환타 1.35배), 시안(범위 +30%), 블루(공격 주기 -20%), 퍼플(빨간 적 데미지 2배→3배·피해감소 ½→0.4), 핑크(공격력 +15%) — 공통 사거리 +20%
- 병합 중 함께 발견/수정한 기존 잠재 버그: 전투 이동 판정 루프와 그린의 부메랑 사거리가 훈련 레벨을 반영하지 않던 문제

## 2. 2진 진화 시각 버그 수정
- 증상: 2진 진화 시 캐릭터가 접지선보다 아래로 "내려가" 보임
- 원인: `.evolved-stick`의 다리(`.leg`) 요소가 `top:44px~69px`로 그려지는데 스틱맨 박스 자체 높이는 `61px`로 설정되어 다리가 박스 하단보다 8px 더 아래로 삐져나감 (코덱스 원본 CSS 수치 오류)
- 조치: 박스 높이를 `61px → 69px`로 수정, 좌표 측정으로 일반 스프라이트 접지선과 일치하는 것을 확인

## 3. HTML 파일 용량 최적화 (base64 이미지 분리)
- 원인 분석: 8.17MB 중 98.9%(8.08MB)가 base64로 인코딩된 이미지였음. base64는 바이너리보다 약 33% 커지는 데다, 캐릭터 프로필 시트(1.2MB) 등 고해상도 이미지 25개가 HTML 텍스트에 그대로 박혀 있었음
- 조치: 중복 제거 후 고유 이미지 25개를 `assets/` 폴더에 개별 `.png` 파일로 추출, HTML의 base64 문자열을 `assets/파일명.png` 상대경로로 치환
- 결과: HTML 파일 8.17MB → 91.7KB, `assets/` 폴더 총 4.7MB
- 검증: 25개 에셋 전부 정상 로드 확인, 전 유닛 스폰·2진 진화 렌더링·48개 스테이지 시뮬레이션 에러 없이 통과

## 4. 1진/2진 설명 문구 분리

- `PROFILE_TEXT_EVOLVED`를 신규 추가해 8명 아군 모두 2진 전용 설명 문구를 작성, 진화 상태에 따라 다른 문구가 표시되도록 수정
