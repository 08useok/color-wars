# 작업일지 - 2026-09-25

대상 프로젝트: `red-battle-doge.html` ("레드 · 세계편" - 냥코 대전쟁 클론)

전날 대규모 레벨/스프라이트 개편 이후 남은 자잘한 버그를 정리한 하루.

## 1. 신규 아군 10명 2진 프로필 사진 교체
- 크림슨~라즈베리 2진 프로필 카드를 전날 새로 넣은 2진 전신 그림(걷기 첫 프레임)으로 표시하도록 변경

## 2. 레드 버튼 가격 표시 버그 수정
- 레드 스폰 버튼이 2진 가격(60원)이 아니라 항상 기본 가격(30원)을 표시·기준으로 활성화 판정을 하던 문제 수정

## 3. 2진 체력바 위치 버그 수정
- 2진 진화 유닛의 체력바가 커진 몸통 한가운데에 가려 보이던 문제 → 2진 키에 맞춰 머리 위로 이동

## 검증 방식
브라우저에서 레드를 2진까지 강화한 상태로 가격 표시·체력바 위치를 직접 확인.
