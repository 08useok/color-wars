# 전투·측정 종합

정리 기준: 2026-11-10. 시험 맵·출격 방식·계정 조건이 다른 결과는 하나의 순위로 섞지 않는다. 이 문서는 측정법과 주요 결론을 합쳤으며 개별 원자료는 보존한다.

## 무엇을 재는가

| 시험 | 의미 | 주의점 |
| --- | --- | --- |
| 기준 덱 + 후보 1칸 | 후보를 넣은 덱과 기준 덱 차이 | 기준 덱 멤버 제거 평가는 비대칭일 수 있음 |
| 2진 ↔ 3진 | 같은 캐릭터의 진화 전후 변화 | 레벨·보물·맵·시드·출격 방식을 같게 해야 함 |
| 속성별 특화 | 특정 적 구성에서의 기여 | 속성 비중만 같아도 실제 위협과 난이도는 다름 |
| 1대1·연승 | 고립된 상대와의 직접 교전 | 고방·메즈·경제가 있는 실제 덱 성능과 다름 |
| 직접 기대 DPS | 한 대상에게 적중할 때 확률 기대값을 적용한 화력 | 범위 피해 합계·메즈 가치·출격 난이도와 다름 |

야옹컴 auto는 비싼 유닛이 고방 자금을 먼저 쓸 수 있다. smart2는 위험 시 저비용 아군을 우선하는 시험 정책이며 게임 UI의 별도 버튼이 아니다. 가능하면 두 방식의 결과를 함께 보고, 더 나은 결과를 선택했다면 그 사실을 적는다.

## 티어 시험 구역

범용 1개와 빨간 적·검은 적·천사·에이리언·떠 있는 적·메탈·좀비·파동 8개로 총 9맵이다. 시험에서는 보상·XP·확정권·클리어 기록을 저장하지 않는다. 실제 게임 연습은 현재 계정의 보유·레벨 조건을 사용한다.

당시 공통 시험 환경은 수입 MAX, 시작 3,000원, 초당 300원, 지갑 18,000원이었다. 예약 적 전부와 좀비 부활 대기까지 처리해야 적 성을 파괴할 수 있어 적 등장 대기시간이 점수에 영향을 준다.

## 결과를 읽는 순서

1. [현재 목록에서 최근 순위 문서](../티어표/8.1-순위-티어표-2026-11-03.md)의 측정 조건을 확인한다.
2. [8.2 추가 점검](../8.2-점검-2026-11-08.md)처럼 이후 캐릭터 검사는 따로 본다. 가까운 점수 구간에 배치한 결과는 전원 재측정이 아니다.
3. 실패·시간 초과의 처리, 기준 덱 비대칭, 동일 점수 정렬 규칙을 확인한다.
4. 한 맵의 결과나 DPS만으로 범용 최강을 단정하지 않는다.
