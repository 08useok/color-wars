## 현재 배포 경로

GitHub Actions가 커밋된 게임 코드·에셋만 묶는다. 로컬의 미커밋 수정, docs·work·reference-sheets·개발 도구는 공개 묶음에 넣지 않는다. 실제 업로드는 약 306MB에서 244MB로 줄었다. 사이트 주소와 저장 키는 유지했다.

구성은 .github/workflows/pages.yml, 묶음은 scripts/build-pages.cjs, 실제 사이트 확인은 scripts/verify-pages.cjs다. 배포 묶음의 _deployment.json에 커밋·버전·파일 수를 기록하고 실제 URL과 대조한다. 성공한 빌드·업로드만으로 사이트 반영 완료라고 보고하지 않는다.

상세 재현과 권한 구성은 [게임 전용 배포 원문](기록/Pages-게임전용-배포-2026-11-10.md)을 본다. GitHub Pages의 syncing_files는 실제 서비스 서버에 파일을 옮기는 단계다. 현재 방식으로도 해당 단계가 실패한 기록을 남겼으며, 내부 원인은 공개 로그만으로 단정하지 않는다.

## 미출시 초안·옛 계획 구분

좀비 전용 레어 3명은 초안이며 코드·뽑기에 등록하지 않았다. 옛 7.5 문서의 라이트 레인보우 ‘8.0 예정’은 당시 기록이고, 후속 8.0 출시 기록이 우선한다. 버전 번호는 [버전 기준](../releases/버전-기준.md)을 따른다.
