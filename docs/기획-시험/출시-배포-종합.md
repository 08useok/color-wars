# 출시·배포 종합

정리 기준: 2026-11-10. 기획·로컬 적용·커밋·푸시·온라인 배포를 서로 다른 상태로 기록한다. 파일에 ‘출시 준비’ 또는 ‘로컬 적용’이라고 적혀 있으면 그 시점의 기록이다.

## 8.6 출시 준비 점검 — 2026-11-16

8.6 콘텐츠는 로컬 연결과 기능 검사를 마쳤다. 사프 1·2진, 신규 3진 5명, 크림·핫 핑크 본능, 고대 사이클론 재강림 2맵, 신레 19~21장 18맵과 신규 적 3종이 대상이다. 신레 간이 전투는 36/36 승리이며 ★2~4 완전 공략·전원 티어 재측정 결과는 아니다.

게임 진입점의 173개 스크립트가 존재하고 구문·로드 순서에 문제가 없는지 확인했다. 신규 출시 확인 목록을 포함해 런타임 리소스 71개와 사프 파츠 32개가 로컬에 존재한다. 그중 64개 리소스 파일은 아직 Git에 들어가지 않은 새 파일이므로, 로컬에서 보인다는 이유만으로 배포에 포함됐다고 판단하면 안 된다.

배포 도구는 버전별로 필요한 리소스를 검사하도록 보완했다. 묶음을 만들 때 누락된 신규 이미지·파츠가 있으면 업로드 전에 실패한다. 배포 후에는 커밋된 버전과 온라인 매니페스트·공지의 버전이 일치하는지 확인하고, 8.6 모듈·3진 시트·프로필·신규 적 시트·사프 파츠 32개를 요청한다. 잘못된 커밋·구버전·404·파츠 누락을 거부하는 검사와 기존 8.5 호환 검사를 통과했다.

패치노트 초안은 [출시 공지 본문](../../work/release86/notice.html), 연결 검사 결과는 [preflight.json](../../work/release86/preflight.json)에 있다. [runtime-paths.json](../../work/release86/runtime-paths.json)은 필요한 실행 파일 목록이며, 다른 작업의 수정까지 전부 커밋하라는 목록이 아니다. 기존 변경을 분리해 검토한 뒤 명시한 파일만 커밋한다. 개발 도구·테스트·문서도 해당 작업 파일을 따로 지정한다.

준비 점검 당시에는 게임 버전 8.5.0을 유지했다. 이후 사용자 출시 승인으로 **8.6.0 버전·공지와 3진 총평의 출시 문구를 적용**했다. 기능 검사와 배포 사전 검사는 통과했으며, 이번 커밋의 푸시 후 GitHub Pages 배포 결과와 실제 사이트 리소스를 확인한다. 커밋만으로 온라인 반영 완료라고 판단하지 않는다.

## 현재 배포 경로

GitHub Actions가 커밋된 게임 코드·에셋만 묶는다. 로컬의 미커밋 수정, docs·work·reference-sheets·개발 도구는 공개 묶음에 넣지 않는다. 실제 업로드는 약 306MB에서 244MB로 줄었다. 사이트 주소와 저장 키는 유지했다.

구성은 .github/workflows/pages.yml, 묶음은 scripts/build-pages.cjs, 실제 사이트 확인은 scripts/verify-pages.cjs다. 배포 묶음의 _deployment.json에 커밋·버전·파일 수를 기록하고 실제 URL과 대조한다. 성공한 빌드·업로드만으로 사이트 반영 완료라고 보고하지 않는다.

상세 재현과 권한 구성은 [게임 전용 배포 원문](기록/Pages-게임전용-배포-2026-11-10.md)을 본다. GitHub Pages의 syncing_files는 실제 서비스 서버에 파일을 옮기는 단계다. 현재 방식으로도 해당 단계가 실패한 기록을 남겼으며, 내부 원인은 공개 로그만으로 단정하지 않는다.

## 미출시 초안·옛 계획 구분

좀비 전용 레어 3명은 초안이며 코드·뽑기에 등록하지 않았다. 옛 7.5 문서의 라이트 레인보우 ‘8.0 예정’은 당시 기록이고, 후속 8.0 출시 기록이 우선한다. 버전 번호는 [버전 기준](../releases/버전-기준.md)을 따른다.
