# 좀비 사이클론과 롤링 데드

## 적용

- 적: 좀비 사이클론(원본 ID 294 / DB 296). 체력 1,222,222, 공격력 44,444, 범위 공격, 간격 5/30초, 선딜 1/30초, 넉백 4회. 원본 사거리 120을 게임 단위 4.1로, 속도 4를 2.68로 환산했다.
- 좀비 속성만 지닌다. 땅굴 없음. 4초 뒤 체력 100%로 무한 부활하며 좀비 킬러로 마무리하면 영구 처치된다.
- 부활 예정인 시체도 보스 처치로 인정하지 않도록 성 보호 판정을 보강했다.
- 강림: 롤링 데드 / 윤회의 소용돌이. 세계편 3장 클리어 후 매일 도전, 성 체력 1,000,000, 적 최대 10명. 기존 스테이지 끝에 1개 추가했다.
- 원작 출현표의 30fps 시간을 환산: 좀비 멍뭉이 6.67초부터 2명, 보스 20초, 멍뭉이 반복 26.67초, 하마 53.33초, 돼지 106.67초, 고릴라 160초, 바다레오파드 213.33초, 캥거류 266.67초부터 각각 8명. 장시간 안내판 적은 이 게임에 별도 등록하지 않아 제외했다.
- 클리어 XP와 슈퍼 레어 응원단 민들레 30% 보상을 연결했다.

## 보상 캐릭터 — 응원단 민들레

- 민들레의 여성 아종, 슈퍼 레어. 1진 응원단 민들레 / 2진 치어리더 민들레. 기존 원본의 노란 몸·초록 목도리·홀씨를 유지하며 하얀 홀씨 폼폼을 쓴다.
- 사거리 안 메탈 우선 공격, 크리티컬 100%, 메탈 킬러 100%, 히트백 4회. 개체 공격이며 비메탈에는 남은 체력 비례 처치가 적용되지 않는다.
- Lv.30·보물 완성·2진·세계편 2/3장 가격: 체력 19,998, 공격력 25,000, 공격 간격 8초, 선딜 1.6초, 사거리 32, 가격 1,350원, 생산 30초. 사각지대 없음.
- 긴 공격 간격·개체 타격·낮은 생존력이 약점이다. 메탈 무리에는 고방과 메탈 메즈가 필요하다.
- 보상 추가 전 XP만 받았던 클리어 기록에는 최초 마이그레이션 때 한 번 지급한다. 신규 확률 드롭에 실패한 기록은 재접속해도 자동 지급하지 않는다.
- 상세 모션·시험·프롬프트: `응원단-민들레-2026-10-28.md`.
