# 8.1 신규 사이클론과 보상 아종

## 구성

|강림(이식명)|보스|해금|보상|
|---|---|---|---|
|태풍 제로 / 원시의 소용돌이|고대 사이클론|구레전드0~323 ★1 클리어|탐사 민트시안30%|
|절망 신차원 / 진격의 워프홀|슈퍼 스페이스 사이클론|우주편1장 빅뱅 클리어|앵커 그레이30%|

강림 이름은 일본어 원본을 바탕으로 한 이식명이다. 기존 맵 뒤에만 추가해 저장 번호를 보존했다. 기존 사이클론의 보스 격파·성 보호·클리어 저장·중복 보상 방지 경로를 재사용한다. 악마는 제외했다. 기존 레드·블랙·화이트·천사·메탈·코스믹·좀비·허리케인에 이번 두 대형 사이클론을 추가했다. 미니스타는 기존등록을 유지하며 후대의 소형 사이클론들은 이번 강림 범위에 포함하지 않는다.
