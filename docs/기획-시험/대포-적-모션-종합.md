# 대포·적·모션 종합

정리 기준: 2026-11-10. 대포 효과·발사 연출·좀비 에셋에 관한 설명을 이 문서로 통합한다. 온라인 반영 여부는 [출시·배포 종합](출시-배포-종합.md)에서 구분한다.

## 대포 5종

기지 강화 → **대포 갈아끼우기**에서 선택한다. 선택은 저장되며 새로고침 후 복원된다. 전투 중에는 일시정지 상태에서도 교체할 수 없고, 교체하면 충전과 남은 연출이 초기화된다.

| 대포 | 효과 | 충전·강화 |
| --- | --- | --- |
| 냥코 대포 | 기존 범위 피해·밀치기 | 기존 위력·충전 강화 |
| 천둥포 | 피해·밀치기 없이 2초 정지 | 기본보다 10초 길며 최소 10초, 정지 무효 제외 |
| 슬로우포 | 피해·밀치기 없이 4초 느리게 | 기본보다 10초 길며 최소 10초, 느리게 무효 제외 |
| 캐논 브레이크포 | 피해·밀치기 없이 베리어 확정 파괴 | 기본보다 10초 길며 최소 10초, 실드는 제외 |
| 천사포 | 좀비에게 대포 위력만큼 피해, 직접 처치 시 부활 방지 | 기본보다 10초 길며 최소 10초, 위력 강화 적용 |

특수 대포는 땅속·출현 중·부활 대기 중인 적을 제외한다. 천사포는 다른 속성에 피해를 주지 않는다. 더 긴 기존 느리게·정지 효과는 줄이지 않는다. 충전 강화는 공유한다.

본체 외형은 유지하고 원작 발사 이펙트만 **30FPS**로 연결했다. 기본 파동 10프레임, 슬로우 32, 천둥 30, 천사 47, 브레이크 40+후속 효과 49프레임이다. 선택한 효과를 전투 전에 불러오며 브레이크포는 두 시트를 준비한다.

## 좀비 전용 그림

색조 필터로 대신하던 9종의 외형을 교체했다. 적 수치·출현표·저장 ID는 유지했다.

| 대상 | 연결 방식 |
| --- | --- |
| 좀비 곰선생·까르삔초·오리룰루 | 기존 cadaverbear·zapy·zuche 전용 시트 재사용 |
| 좀비 샤이 보어·제비족·혹부리 낙타·타조동호회·핫도그·스릴러즈 | 원작 파츠·리그를 확보해 걷기·공격·넉백 269프레임 제작 |

원작 이펙트·적 그림은 새로 그린 이미지가 아니라 원작 파츠·모션을 렌더한 결과다. 사이클론 원작 모션 교체와 좀비 강림도 별도 기록을 보존했다.

## 확인 범위

- 대포별 효과·충전·대상 제외·선택 저장·교체 잠금 검사 통과.
- 실제 브라우저에서 시트 로드·발사·일시정지·종료·교체 정리 확인.
- 좀비 9종 모션 연결, 필터 제거, 전체 적 수치·스테이지·출현표 불변 확인.
- 전 맵 재측정과 모든 적 모션의 전 프레임 육안 검사를 완료했다는 뜻은 아니다.
