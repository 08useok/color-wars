# 7.5·8.0 남은 울슈레 출시 계획

## 사용자 확정 방향

- 7.4 콘텐츠 작업은 여기서 마무리한다. 이 지시는 커밋·푸시·버전 발표 지시를 포함하지 않는다.
- 남은 울슈레는 모두 OP급 성능을 목표로 한다.
- 개체·원거리 개체·범위·원거리 범위·전방위의 다섯 공격 방식을 배분한다.
- 빨간 적+떠 있는 적, 검은 적+에이리언처럼 혼합 속성을 상대한다.
- 전원 초데미지 필수. 계속 공격을 맞힐 때 무한 정지가 가능한 구조로 만든다.
- 바스터즈 전용 뽑기로 출시한다.
- 남은 다섯 후보 중 딱 한 명은 8.0에 출시한다.

## 배분 초안

남은 후보 프로필은 사용자가 앞서 제공한 79~91번 명단 기준이다. 아래 배분과 성능 수치는 대화에서 제안한 뒤 사용자의 “좋다. 이렇게 저장해”에 따라 채택한 계획안이다. 게임 능력치나 출시 코드로는 아직 적용하지 않았다. OP 성능은 구현 후 시험으로 확인한다.

|버전|캐릭터|프로필|공격 방식|혼합 대응 속성|
|---|---|---|---|---|
|7.5|헬리오트로프(헬리)|여성·33세·천연 염색 공예가|원거리 범위|빨간 적·떠 있는 적|
|7.5|위스테리아(위스)|여성·31세·조경 디자이너|전방위|검은 적·에이리언|
|7.5|블로섬|여성·29세·웨딩 플래너|범위|천사·좀비|
|7.5|아몬드 블로섬(아블)|여성·34세·견과류 전문점 사장|개체|빨간 적·검은 적|
|8.0|라이트 레인보우(라레인)|여성·26세·안경사|원거리 개체|에이리언·천사|

라이트 레인보우만 8.0으로 남겨 네 명은 7.5, 한 명은 8.0으로 나누는 안이다. 사용자 정정에 따라 통합 듀얼 바스터즈 배너는 사용하지 않는다. **레드 바스터즈(빨간 적 대항), 블랙 바스터즈(검은 적 대항)**처럼 대응 속성별 전용 뽑기로 나눈다. 배너 대상은 사용자 제안에 따라 빨간 적·검은 적·에이리언·천사·떠 있는 적의 다섯 가지로 정한다. 좀비 전용 바스터즈 배너는 두지 않는다. 떠 있는 적 배너 등 세부 표시 이름과 실제 편성은 후속 확정한다. 혼합 속성 캐릭터가 두 배너 모두에 들어갈지 한 전용 배너에만 들어갈지도 후속 결정 사항이다. 기존 일반 시리즈·축제 풀에 자동 혼입하지 않고 바스터즈 배너에서 획득하도록 설계한다. 뽑기 등장 주기·확률·천장 수치는 아직 정하지 않았다.

## 무한 정지와 초데미지 구현 기준

대응 두 속성에 정지 100%를 부여하고 기본 정지 지속시간을 공격 간격보다 길게 잡는다. 한 번 정지 뒤 다음 타격 전에 효과가 끊기지 않는지 보물에 의존하지 않는 기본 수치로 검증한다. 선딜로 최초 공격이 늦거나 적을 놓친 경우와 정지 무효 적까지 무조건 제어한다는 뜻은 아니다.

개체·원거리 개체는 동일한 한 대상을 계속 맞힐 때 무한 정지, 범위·원거리 범위·전방위는 실제 타격 구간의 대상에게 연속 적중할 때 무한 정지가 가능해야 한다. 원거리 공격 방식은 기존 경험을 반영해 사각지대를 자동으로 추가하지 않고 타격 구간을 명시한다.

초데미지는 정지와 같은 두 속성에 적용한다. 블로섬은 사용자 지정으로 좀비 킬러를 주지 않는다. 천사·좀비 초데미지와 정지는 유지하므로 직접 처치한 좀비도 부활할 수 있다.

## 채택한 성능 목표

공체와 직접 DPS는 **Lv.30·2진·보물 완성 기준 목표치**다. 직접 DPS는 초데미지·조건부 공격력 강화·혼신의 일격을 적용하기 전이다. 실제 구현 시 성장 계수와 보물 배율을 역산해 목표 표시 수치에 맞춘다.

이동속도는 기존 게임 단위다. 공격 간격은 공격 시작부터 다음 공격 시작까지의 주기이며, 선딜과 후딜을 공격 간격에 다시 더하지 않는다. 후딜은 그 주기 안에서 공격 후 움직이지 못하는 시간이다. 나머지 주기는 공격 대기시간으로 구분한다. 정지 시간은 보물로 추가 연장되기 전 기본값으로 두어 보물 없이도 주기보다 1초 길게 유지한다.

|캐릭터|채택한 부가 효과|

|헬리오트로프|공격력 다운 무효·정지 무효|

전원 대응 두 속성에 초데미지와 정지 100%를 부여한다. 원거리형은 사각지대 없이 설계한다. 가격은 **3,500~4,500원**, 생산 대기시간은 **보물 완성 기준 35~50초** 범위부터 시험하며 개인별 정확한 가격과 대기시간은 아직 정하지 않았다. 직접 사거리·원거리 타격 구간·전방위 뒤쪽 타격 거리·1진 수치도 후속 설정 사항이다.

## OP 목표 검증

9개 티어 시험 맵의 기존 고정 기준 분포에서 종합 점수 0.90 이상을 OP 목표로 삼는다. 캐릭터를 추가하면서 기준 분포를 바꿔 등급을 올리는 방식은 사용하지 않는다. 각각의 대응 속성 맵에서는 무한 정지 유지·초데미지 적용·단독 및 덱 기여를 별도로 확인한다.

현재 티어 도구의 실패 진행도 동점 처리와 기준덱 멤버 편향은 별도 한계로 남는다. 새 캐릭터는 성능을 측정하기 전부터 OP 확정이라고 표시하지 않는다. 목표에 못 미치면 공체·공속·사거리·생산성을 조정해 재시험하는 방향이며 OP 목표를 낮추지는 않는다.

## 8.0 전체 아군 대규모 밸런스 조정

사용자 추가 방향: 최근 아군이 지나치게 강해 적의 역할이 드러나지 않는 문제를 해결하기 위해 **전체 아군 캐릭터**를 조정 대상으로 삼는다. 바스터즈 다섯 명이나 현재 OP만으로 범위를 한정하지 않는다. 모든 캐릭터에 동일한 비율의 너프를 적용한다는 뜻은 아니며 대상별 변경 수치는 아직 정하지 않았다.

목표는 적의 사거리·공격 준비·돌진·메즈·베리어·파동 등의 특성이 실제 전투에서 위협이 되고, 고방·메즈·딜러·속성 대항 편성이 의미를 갖게 하는 것이다. 시험 맵 OP 점수만이 아니라 실제 스테이지에서 적이 공격·능력을 발휘할 기회를 얻는지도 확인한다.

검토 항목은 과도한 공체·DPS·양산성, 장거리 공격의 안전성, 무한 정지 등 지속 제어, 초데미지와 복합 강화의 결합이다. 이는 검토 범위이며 구체적인 상한·계수·확률·대기시간 변경은 아직 확정하지 않았다. 약한 캐릭터까지 일괄적으로 약화하거나 적 능력치를 일괄 상향하는 계획으로 해석하지 않는다.

사용자가 언급한 **좀비 적의 무한 부활은 이 정당화에서 별도 예외**다. 아군이 너무 강하다는 이유로 좀비 무한 부활을 추가하거나 강화하지 않는다. 기존 유한 부활의 횟수·좀비 킬러 동작 변경도 이번 계획에서 확정하지 않았다.

7.5 출시 전에는 앞서 채택한 OP 목표로 설계하되, 8.0의 전체 조정에서는 바스터즈도 예외로 두지 않는다. 8.0의 라이트 레인보우 역시 전체 조정 기준으로 출시 성능을 다시 확인한다. 기존 '전원 OP'는 7.5 설계 목표이며 8.0 이후의 영구적인 성능 보장은 아니다.

현재는 계획 저장만 수행했다. 실제 너프·적 수정·캐릭터 보유·성장·저장 기록 변경은 하지 않았다.

## 현재 산출물

출시 계획만 저장했다. 이번 작업에서는 그림·모션·게임 능력치·가챠·스테이지·보유 기록·버전 파일을 변경하지 않았다. 7.4의 기존 미커밋 작업도 그대로 보존했다.
