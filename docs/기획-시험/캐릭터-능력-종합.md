## 사프 전투·뽑기 연결 (2026-11-16, 8.6 로컬)

고대·천사 바스터즈 전용 울슈레로 등록했다. 기존 배너의 천장과 보유 캐릭터는 유지하며, 확정권 뽑기·도감의 획득 링크·강화·덱·출격에 연결했다. 일반 시리즈·축제 풀에는 추가하지 않는다.

| 항목 | 1진 | 2진 |
| --- | --- | --- |
| 체력 | 104,348 | 120,000 |
| 공격력 | 26,088 | 30,000 |
| 무속성 직접 DPS | 8,153 | 9,375 |
| 사거리 / 공격 범위 | 400 / 200~550 | 동일 |

| 이동 속도 / 히트백 | 내부 8 / 3회 | 동일 |

수치는 Lv.30·보물 완성·세계편 2·3장 가격이며 덱 콤보를 제외한다. 세계편 1장 가격은 2,800원이다. 사거리는 냥코식 단위이며 8.0 조정 후 최종값으로 적용했다. 수치는 이번 연결에서 정한 초기안이며 티어를 재측정한 결과는 아니다.
