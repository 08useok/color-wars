# 응원단 민들레 / 치어리더 민들레

민들레의 여성 아종, 슈퍼 레어. 좀비 사이클론 강림 「롤링 데드 / 윤회의 소용돌이」 클리어 시 30% 획득한다. 3진은 미출시 잠금이다.

## 능력과 수치

기준: 합산 Lv.30, 보물 완성, 덱 콤보 없음, 세계편 2·3장 가격.

|항목|1진|2진|
|---|---:|---:|
|체력|17,390|19,998|
|공격력|21,740|25,000|
|공격 간격|8초|8초|
|선딜|1.6초|1.6초|
|사거리|32|32|
|생산 시간|30초|30초|
|가격|1,350원|1,350원|
|히트백|4회|4회|

- 크리티컬 100%·2배, 메탈 킬러 100%. 원본 민들레의 히트백 3회보다 1회 많다.
- 사거리 안에서 공격 가능한 메탈을 우선 조준한다. 메탈이 없으면 일반 적을 공격하며, 사거리 밖·뒤쪽·넉백 중인 메탈은 우선하지 않는다.
- 개체 공격으로 메탈도 한 번에 한 마리만 처치한다. 사각지대는 없다. 비메탈에게는 메탈 킬러가 적용되지 않으며, 무적·베리어로 타격이 막힌 경우 처치하지 못한다.
- 크리티컬과 메탈 킬러 100%를 함께 적용할 수 있도록 100% 메탈 처치 분기를 추가했다. 기존 100% 미만 메탈 킬러와 다른 캐릭터의 피해 규칙은 유지한다.
- 과거 XP만 지급하던 시기의 좀비 강림 클리어 기록에만 1회 소급 지급한다. 최초 접속 시 마이그레이션 완료 표시를 저장해 이후 30% 드롭 실패를 자동 지급으로 바꾸지 않는다.

- 내장 이미지 생성 도구 사용. 참고 원본: `assets/s2_dandelion.webp`, `assets/s2_dandelion_2.webp`.

- 1진은 작은 둥근 몸·초록 목도리·리본, 2진은 초록/크림 응원복과 짧은 노란 옆머리. 두 형태 모두 홀씨 폼폼 두 개를 쓴다.
- 각 형태 16장: 걷기 4, 대기 4, 공격/복귀 7, 넉백 1. 투명 배경·발 위치·머리 중심을 확인했고, 실제 타격 1.6초에 홀씨 분사 그림이 오도록 연결했다.
- 게임 시트·초상·프레임 정보: `assets/cheer-dandelion-motion/`. 재생: `work/cheer-dandelion-motion/preview.html`.

## 검증

- 현재 메탈 적 9종 × 체력 배율 1/10/100/1,000 = 36건을 모두 한 타격으로 처치했다. 일반 적 비즉사·메탈 우선/일반 대상 복귀·개체 타격·범위 밖/뒤쪽 제외 시험도 통과했다.
- 기존 적·아군 능력치와 스테이지·출현표를 보존했다. 메탈 강림 지원 덱으로 시드 1/2/3 모두 35.23초 클리어. 이는 최적 덱이나 티어 판정이 아니다.
- 실제 브라우저: 1·2진 출격, 걷기·대기 각 4장, 공격 7장, 넉백, 타격 시점, 초상화·총평, 30% 보상 실패/획득/중복 방지, 재접속 시 소유·레벨·기본 2진 복원 확인.
- 과거 클리어 소급 지급과 신규 드롭 실패 비소급을 별도 검증했다.
- 도감 회귀: 아군 116명·표시 형태 248개, 형태/보물 480조건, 실제 피해 비교 3,803건 통과.
- 결과: `docs/simulations/cheer-dandelion-2026-10-28.json`, `work/cheer-dandelion-motion/browser-results.json`.
