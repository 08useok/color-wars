## 초보자 공략의 공통 흐름

- 세계편은 레벨 강화와 덱 편성을 먼저 확인한다. 돈이 생길 때마다 수입만 먼저 올리는 시험 정책은 초반 방어 공백을 만들 수 있다.
- 미래편은 에이리언 억제기와 속성 대응을 함께 확인한다.
- 우주편은 출격 제한·별 에이리언 억제기·베리어 대응을 확인한다.
- 좀비 맵은 땅굴과 부활 대기를 포함한다. 직접 처치가 필요한 좀비 킬러와 단순 피해·밀치기를 구분한다.

이 내용은 과거 실제 사이트 플레이 기록의 요약이며 새 계정·현재 밸런스로 전부 다시 플레이한 결과는 아니다.

## 덱을 찾을 때

맵 이름과 별 수, 계정 레벨·보물·3진 보유 조건을 먼저 고정한다. [모든 맵 추천 덱](기록/모든-맵-추천-덱-2026-10-24.md)의 성공 범위는 2026-10-24 당시 조건이다. 오래된 [공통 덱 제안](기록/endgame-deck.md)은 전 맵 승리 검증이 없는 제안이므로 최신 최강 덱으로 취급하지 않는다.
