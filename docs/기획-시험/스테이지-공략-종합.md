# 스테이지·공략 종합

정리 기준: 2026-11-15. 코드의 콘텐츠 범위는 세계편 1~3장·미래편 1~3장·우주편 1~3장·구레 1~49장·신레 0~18장이다. 코드 범위와 현재 온라인 배포 버전은 구분한다.

## 좀비 침공 원작 편성 정비 (2026-11-15)

사용자가 확정한 범위는 세계편 1~3장·미래편 1~3장·우주편 1장의 **7개 장 × 48곳 = 336곳**이다. 우주편 2·3장의 초수·거대·악마가 섞인 습격은 이번에 추가하지 않는다.

일반 스테이지의 적을 좀비 짝으로 바꾸던 방식 대신, 각 습격의 원작 출현표 **2,891개 규칙**을 연결했다. 기존과 비교해 출현 규칙이 달라진 곳은 300곳, 적 성 체력이 달라진 곳은 6곳이다. 321곳은 [Battle Cats DB의 습격 출현표](https://battlecats-db.com/stage/index_future_zombie.html), 개별 DB 페이지가 없는 15곳은 [위키의 개별 습격 문서](https://battlecats.miraheze.org/wiki/Korea_(Empire_of_Cats)/Outbreak)를 사용했다. 각 스테이지의 정확한 출처는 데이터에 함께 기록했다.

### 적용 내용

- 적 종류·배율·유한/무한 출현 수·등장 시각·재등장 간격·성 체력 연동·보스 충격파 조건을 원작 표에 맞췄다. 30프레임을 1초로 변환했다.
- 세계편 2·3장에는 엔진이 장 배율을 따로 곱하므로, 표의 배율을 각각 1.5·4로 나눈 뒤 한 번만 적용한다. 일반 적과 좀비 모두 같은 원칙이다.
- 적 성 체력·동시 적 상한·아군 출격 상한도 각 습격 값으로 적용했다. 잠복 중인 좀비와 부활 대기 중 시체가 침공전의 적 상한에 포함되도록 보완했다. 기존 보스의 상한 예외는 유지한다.
- 일반 장의 최종 스테이지를 깬 뒤 해당 장의 습격이 열리고, 달·빅뱅 습격은 나머지 47곳을 완료해야 열린다. [원작 해금 조건](https://battlecats.miraheze.org/wiki/Zombie_Outbreaks)을 유지했다.
- 일반 스테이지 번호·일반 출현표·적/아군 능력치·저장 키·기존 침공 클리어 ID는 바꾸지 않았다. 새로고침이나 업데이트로 클리어 기록을 초기화하지 않는다.

### 이 게임에 맞춰 유지한 부분

지도에서 습격을 직접 선택하는 방식과, 완료한 습격을 추가 보상 없이 연습하는 방식은 유지한다. 원작의 통조림·통솔력 보상을 새 재화로 추가하지 않고 기존 XP·Z 메달·확정권 보상을 유지했다. [원작의 보상](https://battlecats.miraheze.org/wiki/Zombie_Outbreaks)과 동일한 재화 체계라는 뜻은 아니다.

원작 스테이지 폭은 출처 메타데이터로 보존했고, 실제 전투 좌표·거리·이동속도 환산은 기존 게임 규칙을 사용한다. 다른 스테이지와 마찬가지로 15분 뒤 나타나는 간판 아가씨는 생략한다.

자료 교차 검수에서 스페인 침공 문서의 36.67초/900프레임 표기 충돌을 발견했다. 같은 맵 1·3장의 DB와 초 단위 표기를 교차 확인해 2장도 1,100프레임을 적용했다. 중국·그리스의 동시 출현 행 순서도 다른 장의 DB로 대조했다. 근거는 원자료의 `corrections`에 남겼다.

### 검증과 산출물

- `node scripts/test-outbreak-original.cjs`: 336곳·2,891규칙의 출처 일치, 배율, 해금, 클리어/보상 상태 보존, 잠복·시체 상한, 우주편 출격 제한, 일반 스테이지·능력치 불변 검사 통과.
- `node scripts/smoke-outbreak-original.cjs`: 336곳을 각각 최대 60초 실행해 오류 없는지 확인했다. Lv.30·2진·보물 완성·수입 만렙의 시험 덱에서 보스 등장 지연 보완 후 321곳 승리·15곳 시간 초과였다. 전 맵 완전 공략이나 새 계정 난이도 검증은 아니다. 위 자료 교정이 영향을 주는 네 곳은 수정 후 다시 실행했다.
- 적 도감·신규 좀비 레어·대포 관련 검사도 통과했다. 옛 37곳 보완 검사는 현재 336곳 교체와 분리해 검증한다. 과거 측정 JSON을 검사 실행 때 덮어쓰지 않도록 출력 위치를 작업 폴더로 바꿨다.

## 초보자 공략의 공통 흐름

- 세계편은 레벨 강화와 덱 편성을 먼저 확인한다. 돈이 생길 때마다 수입만 먼저 올리는 시험 정책은 초반 방어 공백을 만들 수 있다.
- 미래편은 에이리언 억제기와 속성 대응을 함께 확인한다.
- 우주편은 출격 제한·별 에이리언 억제기·베리어 대응을 확인한다.
- 좀비 맵은 땅굴과 부활 대기를 포함한다. 직접 처치가 필요한 좀비 킬러와 단순 피해·밀치기를 구분한다.

이 내용은 과거 실제 사이트 플레이 기록의 요약이며 새 계정·현재 밸런스로 전부 다시 플레이한 결과는 아니다.

## 덱을 찾을 때

맵 이름과 별 수, 계정 레벨·보물·3진 보유 조건을 먼저 고정한다. [모든 맵 추천 덱](기록/모든-맵-추천-덱-2026-10-24.md)의 성공 범위는 2026-10-24 당시 조건이다. 오래된 [공통 덱 제안](기록/endgame-deck.md)은 전 맵 승리 검증이 없는 제안이므로 최신 최강 덱으로 취급하지 않는다.

### 성 체력 연동 보스 검사 (2026-11-15)

336개 침공의 보스 규칙은 144개로, 체력 연동 122개·시간 연동 22개다. 체력 조건에서는 기준보다 1 HP 높음·기준값·1 HP 낮음의 경계를 확인했고, 시간 조건에서는 예정 시각 전후를 확인했다. 지연 프레임과 실제 보스 유닛 생성도 검사했다.

발견 및 수정:

- 기존 성 보호 코드가 성을 한 방에 부술 때 보스 규칙을 강제로 활성화하고 지연을 0으로 만들었다. 새 원작 침공의 84개 지연/시간 규칙에 영향을 줄 수 있었다. 침공에서는 성 체력 1 보호는 유지하되 조건·지연을 일반 출현 스케줄러가 처리하도록 바꿨다. 일반 스테이지의 기존 성 보호 정책은 유지한다.
- 미래편 1장 일본의 10초 지연이 소수점 누적 오차로 301프레임이 되는 경우가 있었다. 원작 침공의 타이머 판정에 작은 오차 허용치를 적용해 300프레임에 맞췄다. 조건 체력보다 높은데 보스가 나오는 문제는 없었다.

예: 미래편 1장 일본은 성 체력 99% 이하가 된 뒤 10초 후 보스가 나온다. 세계편 3장 달의 두 보스는 성 체력 조건이 아니라 13.33초·153.33초의 시간 조건이므로 체력을 낮춰도 예정 시간을 건너뛰지 않는다.

검증: `node scripts/audit-outbreak-boss-triggers.cjs`의 144규칙 경계·지연·실제 생성·치명타 성 보호 검사가 모두 통과했다. `test-boss-castle-guard.cjs`는 일반 보스 맵 505곳에서 기존 동작을 확인했다(12곳 잠김/별도 조건으로 제외). 336곳 60초 실행 검사도 다시 수행해 321승·15시간 초과였으며, 긴 시간 조건이 있는 맵의 시간 초과를 오류로 해석하지 않는다.
