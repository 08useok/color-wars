# 7.5 바스터즈 전투·뽑기 연결

헬리오트로프·위스테리아·블로섬·아몬드 블로섬 4명을 1·2진 전투와 전용 뽑기에 연결했다. 라이트 레인보우는 모션 에셋만 유지하며 아군·가챠 풀에 등록하지 않아 8.0 출시 계획을 유지한다. 버전 파일 변경·커밋·푸시는 하지 않았다.

## 전투

성장·진화·보물 공식을 역산해 채택한 Lv.30·2진·보물 완성 목표에 맞췄다. 기존 캐릭터의 성장 공식은 바꾸지 않았다. Lv.1·1진이나 보물이 덜 모인 계정은 실제 표시 수치가 더 낮다.

|캐릭터|체력|기본 공격력|기본 직접 DPS|공격 간격|정지 기본 시간|이속|세계편 2·3장 가격|보물 완성 재생산|
|---|---:|---:|---:|---:|---:|---:|---:|---:|
|헬리오트로프|180,000|75,000|25,000|3초|4초|12|4,200원|40초|
|위스테리아|400,000|40,000|20,000|2초|3초|16|4,000원|40초|
|블로섬|280,000|62,500|25,000|2.5초|3.5초|14|4,000원|40초|
|아몬드 블로섬|350,000|75,000|50,000|1.5초|2.5초|22|3,800원|35초|

가격·재생산·사거리는 계획 범위 안에서 이번 연결에 사용한 초안이다. 세계편 1장 표시 가격은 기존 규칙의 2/3 할인으로 달라진다. 공격력·DPS는 초데미지·혼신의 일격·체력 조건 강화를 적용하기 전이다.

- 헬리: 빨간 적·떠 있는 적 초데미지+정지 100%, 원거리 범위. 공격 시작 거리 26, 앞쪽 타격 0~40, 사각지대 없음. 공격력 다운·정지 무효.
- 위스: 검은 적·에이리언 초데미지+정지 100%, 전방위. 공격 시작 거리 18, 앞쪽 0~24·뒤쪽 18까지 타격. 밀치기 무효, 체력 50% 이하 공격력 2배.
- 블로섬: 천사·좀비 초데미지+정지 100%, 범위. 공격 시작 거리 24, 앞쪽 0~28 타격. 정지·독 피해 무효. 좀비 킬러 없음.
- 아블: 빨간 적·검은 적 초데미지+정지 100%, 개체. 사거리 12, 공격력 다운 무효, 30% 확률 3배 혼신의 일격.

독 피해 무효는 전용 `game.inPoison` 피해 컨텍스트에서 동작하며 보통 공격은 막지 않는다. 현행 적의 독 공격을 새로 추가하지 않았다. 정지는 대응 속성을 계속 맞히는 경우에 유지되며, 공격이 끊기거나 대상이 범위 밖으로 나간 경우까지 보장하지 않는다.

## 전용 뽑기

기존 뽑기 화면 안에 다섯 바스터즈 선택 버튼을 추가했다. 전용 배너는 직접 선택하고, '오늘의 시리즈'로 기존 한국 시간 일일 로테이션에 돌아갈 수 있다. 기존 로테이션 순서와 날짜 계산은 변경하지 않았다.

|배너|전용 울슈레|
|---|---|
|레드 바스터즈|헬리오트로프·아몬드 블로섬|
|블랙 바스터즈|위스테리아·아몬드 블로섬|
|에이리언 바스터즈|위스테리아|
|천사 바스터즈|블로섬|
|떠적 바스터즈|헬리오트로프|

대응하는 혼합 속성 배너 두 곳에 함께 편성하는 방식을 채택했다. 4명은 기존 일반 시리즈·울트라/하이퍼 축제 풀에서 제외한다. 레어·슈퍼 레어는 기존 공통 풀, 확정권 사용·미보유 우선·50회 천장·중복 처리도 기존 규칙을 따른다. 전용 배너의 울슈레 확률은 기존 시리즈와 같은 가중치 .06이므로 정규화 후 약 12.77%(화면 반올림 13%)다. 새로운 무료 캐릭터·확정권 지급은 없다.

가챠 초기 로더가 미등록 시리즈 천장을 버리는 기존 구조에 맞춰 초기 원본의 바스터즈 천장을 보관했다가 복원한다. 재접속 때 천장이 초기화되지 않는 것을 확인했다. 기존 천장과 보관함·확정권 잔액은 유지한다.

## 검증

`scripts/test-busters-75.cjs`: 기존 모든 아군·맵·스폰 보존, 계획 공체/DPS/재생산, 실제 전방·뒤쪽·개체 타격, 대응 속성 정지 12초 연속 유지, 독 피해 컨텍스트 면역, 8개 형태의 전용 시트·프로필·좌표를 확인했다.

브라우저는 별도의 임시 localhost 주소와 시험 계정으로 확인해 원래 게임 계정의 저장 기록을 건드리지 않았다. 실제 가챠 함수의 50회 천장을 강제로 준비해 네 명 획득·확정권 4장 소모·배너 제한을 시험했고, 재접속 후 소유 4명·잔액 6장·레드 천장 17회·블랙 천장 9회·레벨 30 복원을 확인했다. 실제 뽑기 화면에 다섯 버튼이 표시되고, 1·2진 8개 전투 유닛이 각 WebP 시트를 사용해 출격하는 것을 브라우저 상태와 DOM으로 검증했다. 독립된 스크린샷 촬영은 도구 시간 초과로 확보하지 못했으며 화면 스냅샷과 이미지 로드 검증 결과를 근거로 기록했다.
