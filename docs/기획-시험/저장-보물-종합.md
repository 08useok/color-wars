# 저장·보물 종합

정리 기준: 2026-11-10. 저장 안전과 보물 적용 원칙을 한곳에 모았다. 아래 원문은 서로 다른 개발 시점의 기록이다.

## 우주편 2장 저장 보호

| 문제 | 적용한 보호 |
| --- | --- |
| 추가 스테이지 복원 전에 자동 저장이 실행됨 | 등록·복원이 끝나기 전 진행도 저장을 차단 |
| 구버전 탭이 공용 진행 기록을 덮어씀 | 우주편 2장 전용 백업과 확인된 클리어를 병합 |
| 전체 스테이지 번호가 변경됨 | 장 내부 위치 0~47을 별도 저장 |

전용 키는 red-battle-cosmos2-clears-v1이다. 기존에 확인된 클리어만 이관하며 이미 양쪽에서 사라진 기록을 추정해 지급하지 않는다. 손상 JSON·잘못된 값도 걸러낸다. 동일 호스트·브라우저 저장 공간을 유지하는 배포 변경과, 다른 주소로 이전하는 작업은 구별한다.

## 보물 자동 적용

- 세계편은 각 장 달 클리어 기록에서 해당 장 보물 완성 효과를 계산한다. 세계편 3장분은 합산하며 기존 계정에도 소급된다.
- 미래편은 장 클리어와 중간 억제기 기록을 함께 보며 같은 효과를 중복 지급하지 않는다. 과실 보물은 원래 해당 능력을 가진 아군의 효과를 보강한다.
- 우주편은 장별 보물·별 에이리언 억제기·가면 조건을 연결한다. 우주편 2·3장이 없던 시절의 문서 문구를 현재 콘텐츠 범위로 읽지 않는다.
- 보물 효과와 스폰 자체의 배율, 아군 레벨·형태 배율은 별도 조건이다.

세계편의 공체 +50%씩 3장 합산은 기본 대비 2.5배라는 당시 계산이며, 이것만으로 현재 캐릭터의 최종 표시 수치를 정하지 않는다. 전체 세부 수치와 출처 차이는 [전편 보물 기록](기록/전편-보물-자동완성-2026-10-17.md)과 [세계편 기록](기록/세계편-보물-자동완성-2026-10-17.md)을 확인한다.

## 검사와 작업 원칙

- 실제 사용자 세이브 대신 격리된 저장소로 초기화·저장·재로딩을 재현한다.
- 정상 로딩, 조기 저장, 구버전 덮어쓰기, 새 클리어 병합, 손상·잘못된 항목을 구분한다.
- 관련 검사는 scripts/test-cosmos2-save-race.cjs, test-cosmos2-chapter-save.cjs, test-progress-ready-80.cjs다.
- 저장 파일을 지우거나 불확실한 클리어를 만들어 내는 방식으로 복구하지 않는다.

온라인 업데이트가 안 보일 때는 저장 삭제보다 먼저 실제 제공 버전과 배포 결과를 확인한다. [출시·배포 종합](출시-배포-종합.md) 참고.
