# 기존 사이클론 원본 모션 교체

- 대상: 레드(원본 ID 64), 화이트(69), 블랙(70), 천사(112).
- 자료: https://battlecatsinfo.github.io/ 의 `/img/e/{id}/a` 원본 모션과 `/img/e/{id}/c.png` 부품 시트. 신규 그림 생성·색상 재해석 없이 원본 리그를 렌더링했다.
- 기존에 사용하던 원본 렌더러 `battlecatsinfo/battlecats-animation-typescript`(로컬 보관 MIT 소스)를 사용했다.
- 각 시트: 회전 37프레임(8/30초 간격), 공격 2프레임(2/30초 간격), 넉백 1프레임. 투명도와 프레임 경계를 확인했다.
- 연결: `cyclone-original-atlases.js`, 실제 진입점 및 전체 전투 시험 도구에 같은 순서로 포함했다. 메탈·코스믹 시트는 유지했다.
- 능력치·사거리·타격 간격·스테이지 번호·출현표·보상·다른 캐릭터의 에셋은 교체 전후 동일함을 시험했다(`scripts/test-cyclone-original.cjs`).
- 원본 다운로드: `reference-sheets/cyclone-original/raw/`. 렌더링/포장: `scripts/bake-cyclone-original.cjs`, `scripts/pack-cyclone-original.py`.
- 재생: `work/cyclone-original/preview.html`. 이 작업에는 신규 사이클론 추가나 커밋·푸시가 포함되지 않는다.
