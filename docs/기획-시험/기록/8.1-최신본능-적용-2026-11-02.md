# 최신 확정안 적용

- 아쿠아3진: 공격력10단계·레벨당+30%(최대+300%,4배), 떠있는 적 추가1단계, 파동 피해·정지 시간·고대의 저주 시간 내성 각5단계·최대50%. 기본 느리게 대상은 에이리언·천사이며 떠적 본능 구매 시 떠있는 적을 더한다.
- 인디고3진: 범위 공격·정지확률80%·고대종 추가는 각각1회 구매 즉시 적용. 생산시간10단계·최대30% 감소, 저주시간 내성10단계·최대70% 감소.
- 라이트 크림3진: 본능 구매와 관계없이 고대의 저주 무효 추가.
- 본능은 기존 구매 경로의 단계당100,000 XP를 유지. 기존 아쿠아 공격·내성 구매 레벨은 이관하며, 이미 구매한 구형 체력 강화는 보존하되 신규 구매는 제공하지 않는다.

`talents-81-v2.js`로 로더를 전환했다. 사용자 요청으로 테스트·브라우저 검증은 생략했다. 로컬 적용만 했으며 커밋·푸시하지 않았다.
