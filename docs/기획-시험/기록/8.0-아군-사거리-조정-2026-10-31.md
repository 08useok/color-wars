# 8.0 아군 전체 사거리 조정 · 2026-10-31

현재 출시된 275개 형태(1·2·3진)의 직접 사거리에 승인된 구간별 축소를 로컬 게임에 적용했다. 원래 사거리를 냥코식 정수로 환산해 구간을 선택하고, 축소한 값을 10 단위로 내린다. 엔진 내부 좌표는 그대로 두고 냥코식 거리 ×0.034로 저장한다.

|기존 사거리|축소율|
|---|---:|
|1~400|10%|
|401~500|20%|
|501~800|30%|
|801 이상|40%|

원래 공격 시작 사거리로 한 번 정한 비율을 타격 범위·전후방 범위·연타별 사거리·거리별 직접 피해 경계에도 동일하게 적용한다. 거리를 다시 조회해도 중복 축소되지 않는다. 거리별 피해량·관통 횟수·연타 비율과 시점은 바꾸지 않는다. 파동 레벨·파동 도달 거리·열파 범위는 별도 능력으로 이번 직접 사거리 축소에서 제외했다. 적 능력치와 공체·공속·이속·비용·생산 시간은 보존했다.

도감과 아군 버튼 툴팁·기본 총평의 수치 표기를 냥코식으로 바꾼다. 적 도감도 비교 가능한 같은 단위로 표시하지만 실제 사거리는 바꾸지 않는다.

루비의 미출시 3진은 명시적으로 정한 300을 그대로 적용하는 예외를 준비했다. 이 작업이 3진을 해금하는 것은 아니며 기존 루비 2진은 다른 2진과 동일한 구간별 축소 대상이다. 모스 3진 등 미출시 3진은 이후 능력치 등록 후 이 공통 규칙을 적용한다.
