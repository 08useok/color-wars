# 좀비 색칠 에셋 교체

일반 적 그림에 색조 필터를 입히던 구형 좀비 9종의 외형만 교체했다. 능력치·스테이지·출현표·저장 ID는 유지했다.

| 게임 ID | 원작 전용 그림 |
| --- | --- |
| zbear | 기존 cadaverbear 시트 재사용 |
| zcapy | 기존 zapy 시트 재사용 |
| zduche | 기존 zuche 시트 재사용 |
| zbore | 원작 모션 428 (DB 430) |
| zbrollow | 원작 모션 527 (DB 529) |
| zcamelle | 원작 모션 310 (DB 312) |
| zostrich | 원작 모션 698 (DB 700) |
| zdagshund | 원작 모션 744 (DB 746) |
| zthrillerz | 원작 모션 469 (DB 471) |

자료는 `https://battlecatsinfo.github.io/img/e/<모션번호>/a`와 `c.png`. 원본 파츠와 리그를 기존 렌더러로 재생해 걷기·공격·넉백 시트를 만들었다. 신규 6종 총 269프레임. 원본은 `reference-sheets/zombie-originals/raw`, 재생산 도구는 `scripts/fetch-zombie-originals.cjs`, `bake-zombie-originals.cjs`, `pack-zombie-originals.py`.

`zombie-original-atlases.js`와 `zombie-original-motion.js`를 게임 및 전투 시험기에 연결했다. 구형 CSS 색조 필터도 제거했다.

검사: 9종의 시트 존재·걷기/공격/넉백 프레임, 변경 전후 전체 능력치·스테이지·출현표 동일성을 확인했다. 브라우저 검사 결과는 `work/zombie-originals/browser.json`에 저장한다.

로컬 적용이며 커밋·푸시는 하지 않았다.
