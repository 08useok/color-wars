# 8.3 기본 캐릭터 8명 3진 초안

2026-11-09 후속 적용 완료: 전용 3진 그림·30FPS 모션·전투·도감 연결과 검증을 마쳤다. 최신 상태는 `8.3-기본8명-3진-적용-2026-11-09.md`를 참조한다. 아래는 당시 확정한 설계 기록이다.

## 확정 공통 규칙

- 레드·그린·블루·오렌·옐로·퍼플·핑크·시안의 3진을 추가한다.
- 체력과 공격력은 각각 2진의 200%, 즉 2배로 한다. 이전 캐릭터별 공체 배율 제안은 이 수치로 대체한다.
- 생산 대기시간은 모든 감소 효과 적용 후에도 최소 2초다. 레드는 이미 2초이므로 생산 대기시간 감소를 추가하지 않는다.
- 레드·옐로를 제외한 6명에게 효과를 추가한다.

## 캐릭터별 초안

마지막 열의 추가 효과는 승인된 초안이다. 퍼플은 느리게 무효를 빨간 적 대상 50%·3초 저주로 대체한다. 레드·옐로의 이전 초안 능력은 유지하는 것으로 해석했다.

| 캐릭터 | 기존 강화 초안 | 이번 추가 효과 제안 |
|---|---|---|
| 레드 | 냥코식 사거리 140→160, 생산 대기시간 2초 | 추가 없음 |
| 그린 | 부메랑 왕복 모두 범위 타격, 돌아오는 피해 강화 | 30% 확률로 적 밀치기 |
| 블루 | 이동속도 20% 증가, 공격력 다운 무효 | 치명상을 받을 때 50% 확률로 한 번 살아남는다 |
| 오렌 | 과즙 범위 30% 확대, 처치 돈 보너스 강화 | 빨간 적을 50% 확률로 2초간 느리게 한다 |
| 옐로 | 파동 무효, 느리게 무효 | 추가 없음 |
| 퍼플 | 빨간 적 엄강 유지, 빨간 적의 공격력을 50% 확률로 3초간 절반으로 낮춘다 | 빨간 적에게 50% 확률로 3초간 저주 |
| 핑크 | 느리게 확률 60%, 지속 2.5초, 선딜 0.2초 | 30% 확률로 1초간 정지 |
| 시안 | 떠 있는 적 엄강 유지, 사각지대 삭제, 공격 간격 2.8초 | 떠 있는 적을 50% 확률로 2초간 정지 |

그린의 귀환 피해 배율과 오렌의 처치 돈 보너스 수치는 미정이다. 핑크의 정지는 기존 느리게와 같은 대상 범위를 따르는 제안이다.

초안 작성 당시에는 미적용 상태였으며, 2026-11-09에 기존 일반 3진 진화 재료 규칙과 함께 적용했다.
