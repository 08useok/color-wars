# 7.2 3진 네 명 — 승인된 능력 초안

사용자 승인 내용을 `four-third-form-drafts.js`에 등록했다. 기존 1·2진과 저장 기록은 유지한다. **전용 3진 모션이 아직 없으므로 실제 게임 진화는 ‘곧 출시 예정’ 잠금을 유지한다.** 외형 그림은 검토용이며 모션 등록과 별개다.

공체 수치는 Lv.30·보물 완성, 배율은 기존 2진을 기준으로 한다. ‘200% 증가’는 기존의 300%라는 뜻이다.

|캐릭터|체력|공격력|3진 능력|
|---|---:|---:|---|
|라벤더|150% · 105,053|140% · 18,032|공격력 다운 100%·7초, 느리게 100%·3초, 공격 주기 4→3초, 체력 50% 이하 공격력 2배|
|아쥬르|300% · 283,764|300% · 50,400|크리티컬 20%·2배, 혼신의 일격 30%·3배, 10레벨 파동 30%, 돌진 범위 유지|
|아쿠아|150% · 51,620|250% · 9,200|떠 있는 적·천사 느리게 100%·8초, 개체 공격 유지|
|베이비 블루|150% · 35,925|250% · 7,345|밀치기 70%, 개체 공격 주기 1.5→0.75초, 생산 대기시간 80% 단축, 표시 가격 30원 감소|

## 해석·가격·모션 주의

- 라벤더 2진은 실제 판정상 선딜이 없으므로 ‘선딜 −1초’는 적용하지 않고 즉시 타격을 유지한다. 약화 지속시간은 기존 6초에 1초를 더한 기본 7초다.
- 아쿠아의 기본 슬로우는 4.5+3.5=8초. 상태 이상 보물에 따른 실제 지속시간 보정은 기존 규칙을 따른다.
- 베이비 블루는 연구력 적용 후의 대기시간을 기존의 20%로 줄인다. 보물 완성 기준 19→3.8초. 콤보는 이후 기존 규칙으로 적용한다.
- 베이비 블루 가격은 현재 장의 표시 가격에서 30원을 뺀다. 세계편 1장 330→300원, 세계편 2·3장 495→465원.
- 아쥬르 파동은 현재 게임의 원작 단위 환산에 맞춘 길이 77.1을 쓰며, 메타데이터에 레벨 10을 명시한다. 직접 공격 사거리와 별개다.
- 크리티컬·혼신의 일격은 기존 실제 피해 처리기를 재사용한다. 아쥬르의 발동 확률과 돌진·파동 결합을 시험했다.

## 검증

- 전용 그림이 없으면 네 명 모두 3진 잠금, 1·2진 수치 유지 확인.
- 확정 외형의 전용 16프레임 아틀라스를 네 명 모두 게임에 등록했다. 시험도 실제 등록 아틀라스를 사용하며, 별도 격리 환경에서 아틀라스만 제거해 미출시 잠금 규칙을 확인한다.
- 실제 피해 처리로 라벤더의 체력 50% 경계 강화, 아쿠아의 떠 있는 적/천사 슬로우와 빨간 적 제외, 아쥬르 파동 발동/미발동을 검증했다.
- 실행: `scripts/test-four-third-form-drafts.cjs`.
- 결과: `docs/simulations/four-third-form-drafts-2026-10-28.json`.
