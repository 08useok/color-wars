# 세계편 클리어 보물 자동 완성

세계편 1·2·3장의 달을 클리어하면 해당 장의 최고급 보물을 모두 모은 효과를 자동으로 적용한다. 별도 보물 뽑기나 저장 키는 추가하지 않았다. 기존 `cleared`의 세계편 달 기록에서 적용 장 수를 계산하므로 기존 저장에도 소급되고 재클리어해도 중복되지 않는다. 미래편·레전드 클리어는 장 수를 늘리지 않는다.

| 효과 | 장마다 | 세계편 3장 모두 완료 |
|---|---:|---:|
| 모든 아군 체력·공격력 | +50% | 기본 대비 ×2.5 |
| 자연 수입 | +100% | 기존 경제 강화 적용 수입 ×4 |
| 지갑 상한 | +1,000 | +3,000 |
| 처치 수입 | +50% | 회계 강화 적용 수입 ×2.5 |
| 클리어 XP | +50% | 공부력 적용 보상 ×2.5 |
| 아군 생산 대기시간 | −1초 | −3초 |
| 아군 성 체력 | +7,000 | +21,000 |
| 대포 위력 | +500 | +1,500 |
| 대포 충전 시간 | −5초 | −15초 |

보물끼리는 장 수에 따라 합산한다. 공체는 1.5³이 아니라 1+0.5×3이다. 경제 XP 강화 효과에 보물 배율을 곱한다. 연구력 콤보는 보물로 줄어든 생산 대기시간에서 추가 차감하며 2초 미만으로 줄이지 않는다(원래 2초보다 짧은 개체는 늘리지 않음). 이 게임의 대포 기본 충전이 원본과 다르므로 충전 시간에는 1초 하한을 둔다. 기본 성 방어 강화 수치는 그대로 두고 보물 체력을 더한다.

원본 경영 관련 보물의 통솔력 상한 +60/장은 이 게임에 통솔력 소모 체계가 없어 대응 효과가 없다. 이번 변경 때문에 새로운 입장 제한이나 에너지 체계를 만들지 않았다. 따라서 해당 항목을 포함한 원본의 모든 시스템을 복제했다는 뜻은 아니다.

아군의 1·2·3진 및 추가 스크립트 캐릭터에 적용하고 적 능력치는 바꾸지 않는다. 거리별 피해도 함께 강화한다. 정수 반올림이 3진 배율 적용 전후에 있으므로 일부 최종 수치는 계산 순서에 따라 1 정도 차이 날 수 있다. 라즈베리 사각 제거·관통 10명 등의 능력 초안은 여전히 시험 환경에만 있으며 이번 기능 배포에 끼워 넣지 않았다.

## 검증

`scripts/world-treasures-browser-test.cjs`: 완료 장 수 0~3, 전체 아군의 1·2진 공체·거리별 피해·생산 시간, 적 불변, 3진 중첩, 연구력 소 콤보, 대포 하한, 실제 첫 클리어 처리, 재클리어 중복 방지, 재접속 저장 유지 통과. 결과 `work/world-treasures/test-results.json`.

기존 수입 8단계·3진 콤보 브라우저 회귀 검사도 통과했다. 보물 완성 3장으로 라즈베리 최신 시험 초안을 22조건×6시드×2방식×기존/초안 = 528회 추가 실행했다. 세계편 3장 달 8/12, 미래편 1장 달 12/12, 미래편 2장 달 10/12로 개선됐으나 기준 고난도 5맵은 여전히 0/12였다. 3진 시험이므로 전체 3장 보물을 가진 상태로 과거 맵을 재도전한 결과이며 첫 진행 난이도 결과가 아니다. 원자료 `docs/simulations/raspberry-world-treasures-solo-2026-10-17.json`, 재현 `scripts/test-raspberry-world-treasures.cjs`.
