# 8.0 신규 3진 확정 방향

- 하시엔다·라이트 크림·모스·루비 모두 기존 속성 대응을 유지하고 고대종 대응을 추가한다.
- 루비(승인): 공체 각각 기존 2진의 150%, 빨간 적·고대종 대상 범위 공격·정지 확률100%, 정지 기본 지속시간2초→3초(+1초), 공격 간격3초 유지. 사거리는 냥코식 약424에서 **300**으로 조정한다(내부14.4→10.2). 기존 1·2진 사거리를 함께 변경하는 지시는 아니다. 연속 적중 시 기본 정지 시간이 공격 간격과 같으며, 실제 유지 여부는 선딜·명중·저주·보물 적용을 포함해 검사해야 한다. 저주 무효는 아직 확정하지 않았다.
- 모스: 체력·공격력을 각각 기존 2진의 150%로 강화한다. 사거리는 기존 내부 단위에서 +3. 에이리언·고대종·떠 있는 적에게 기존 느리게와 50% 확률·3.08초 저주를 적용하는 안이다.
- 이후 사용자에게 설명하는 사거리는 냥코식 단위를 사용한다. 기존 엔진 환산은 원작 사거리 ×0.034이므로 표시 시 내부 사거리 ÷0.034로 환산한다. 이번 +3은 앞서 내부 단위로 논의한 증가량으로 해석하며 냥코식 약+88.2다. 내부 전투 좌표를 직접 원작 단위로 바꾸지 않는다.
- 네 명의 3진 그림과 미정 강화 수치·저주 엔진은 별도 제작이 필요하다. 이 문서는 확정 방향을 기록한 것으로 게임 능력치를 적용한 기록이 아니다.
