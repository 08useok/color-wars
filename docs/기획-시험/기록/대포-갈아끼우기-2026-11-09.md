# 대포 갈아끼우기

기지 강화의 **대포 갈아끼우기**에서 전투 전에 선택한다.

| 대포 | 효과 | 충전 |
| --- | --- | --- |
| 냥코 대포 | 기존 피해와 밀치기 유지 | 기존 충전 시간 |
| 천둥포 | 피해·밀치기 없이 나온 적을 2초 정지 | 기본 대포보다 10초 길며 최소 10초 |
| 슬로우포 | 피해·밀치기 없이 나온 적을 4초 느리게 | 기본 대포보다 10초 길며 최소 10초 |
| 캐논 브레이크포 | 피해·밀치기 없이 나온 적의 베리어 확정 파괴 | 기본 대포보다 10초 길며 최소 10초 |
| 천사포 | 나온 좀비에게 대포 위력만큼 피해, 직접 처치 시 부활 방지 | 기본 대포보다 10초 길며 최소 10초 |

- 천둥포는 정지 무효 적·땅속 좀비·부활 대기 중인 적에는 적용되지 않는다.
- 슬로우포는 느리게 무효 적을 제외하며 더 긴 기존 느리게를 줄이지 않는다. 브레이크포는 실드를 파괴하지 않는다.
- 신규 특수 대포도 땅속·부활 대기 중인 적을 제외한다. 천사포는 다른 속성에 피해를 주지 않는다.
- 충전 강화는 공유하며 위력 강화는 기본 대포와 천사포에 적용된다.
- 선택을 저장하고 새로고침 후 복원한다. 교체하면 충전이 초기화된다.
- 진행 중인 전투에서는 일시정지 상태에서도 교체할 수 없다.

## 확인 결과

- 자동 검사: 선택 저장, 잘못된 선택 거부, 전투·일시정지 중 교체 잠금, 충전 소비, 천둥포의 대상 제외 조건, 기본 대포의 기존 피해·밀치기 통과.
- 브라우저: 선택·새로고침 복원·교체 잠금·적 2초 정지와 피해 및 위치 유지 확인. 오류 없음.
- 실제 스테이지 클리어 여부는 측정하지 않았다.
- 추가 3종은 전투 자동 검사로 느리게 지속시간·무효, 베리어 파괴·체력 유지, 좀비 피해·처치 후 부활 방지·땅속/시체 제외를 확인했다. 추가 3종의 브라우저 화면 검사는 하지 않았다.

로컬 적용이며 이번 작업에서는 버전 변경·커밋·푸시하지 않았다.
