# 우주편 2장 반복 초기화 보강

로딩 중 자동 저장 차단은 기존 수정에 포함돼 있다. 추가로 우주편 2장 기록을 `red-battle-cosmos2-clears-v1`에 0~47의 장 내부 번호로 보관한다. 확인된 기존 기록만 자동 이관하고, 예전 탭이 공용 기록을 덮어써도 별도 기록을 합쳐 복원한다. 새 클리어 저장 시에도 두 기록을 병합한다. 전체 스테이지 번호가 변경돼도 별도 기록은 같은 장의 같은 위치를 가리킨다.

실제 사용자 저장은 읽거나 변경하지 않았다. 공용·별도 기록 양쪽에서 이미 사라진 기록은 만들어내지 않는다. 사이트·브라우저·로컬 파일 주소가 바뀌어 저장 공간 자체가 다른 경우에는 별도 이관이 필요하다.

검증: `test-cosmos2-chapter-save.cjs`, `test-cosmos2-save-race.cjs`, `test-progress-ready-80.cjs` 통과. 기존 기록 이관, 구버전 탭의 공용 기록 덮어쓰기, 추가 클리어, 잘못된 값 제외, 없는 클리어 미지급을 독립 저장소로 검사했다. 실제 리셋이 발생한 주소는 사용자 확인 대기 중이다.
