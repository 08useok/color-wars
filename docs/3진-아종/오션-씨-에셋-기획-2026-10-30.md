# 오션·씨 1·2진 에셋

사용자 확정: 7.4 해양 탐사의 오션·씨 외형과 모션부터 제작한다.

- 오션: 남성, 35세, 해양 기상 관측원. 풍속계와 관측 부이를 사용한다.
- 씨: 여성, 28세, 스쿠버다이빙 강사. 물안경·잠수 장비와 짧은 작살을 사용한다.
- 1진은 둥근 몸에 작은 손·발과 직업 소품, 2진은 머리와 간단한 직업복으로 구별한다.
- 색상은 외형 초안으로 오션 `#0077be`, 씨 `#008c95`를 사용한다. 사용자 지정 코드로 확정된 것은 아니다.
- 형태별 대기 4·걷기 4·공격/복귀 7·넉백 1장, 총 64프레임을 제작했다.

검증: 4개 형태·64프레임·16개 GIF, 투명 배경·프레임 경계·서로 다른 걷기 4장과 미리보기 파일 검사를 통과했다. 결과는 `work/ocean-sea-motion/validation.json`에 저장했다. 전투 연결은 아직 하지 않았다.

기본 내장 imagegen 도구로 형태별로 생성한다. 생성 프롬프트와 원본은 `reference-sheets/ocean-sea-motion/`, 최종 시트·프로필·좌표는 `assets/ocean-sea-motion/`, GIF와 미리보기는 `work/ocean-sea-motion/`에 둔다. 패키징은 `scripts/pack-ocean-sea-motion.py`로 프레임 분리·정렬만 수행한다.

이 작업에서는 전투 능력치·획득 방법·스테이지·저장 기록을 변경하지 않는다. 게임에 연결하기 전 에셋 제작 단계다.
