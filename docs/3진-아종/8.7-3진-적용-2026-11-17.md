# 8.7 신규 3진 로컬 적용

네 명의 승인된 파츠 조립과 대기·걷기·공격·넉백을 전투용 시트로 내보내고 실제 게임에 연결했다. 최초 연결 당시 버전은 8.6.1이었다. 2026-11-21에 8.7.0 출시 대상으로 확정했다.

후속으로 [540판 전투 비교](8.7-3진-전투비교-2026-11-17.md)와 브라운 전방 범위 원인 분리 시험 18판을 완료했다. 아래의 60초 스모크 검사는 최초 연결 확인 기록이다.

## 능력

| 3진 | 변경 |
| --- | --- |
| 급류 구조대 아쿠아마린 | 체력 2배, 독 무효, 밀치기 60%, 공격 간격 2.6→2.08초. 공격력·기존 파동 무효·밀치기 대상 유지. |
| 안전대장 코발트 | 체력·공격력 각각 2배, 가격 10% 인하, 공격력 다운 무효. 에이리언 엄강 유지. |
| 쌍방패 브라운 | 공격력 +50%, 공격 간격 1초, 앞 100~뒤 -100 전방위 공격, 떠 있는 적 맷집 추가. 천사 맷집·기존 체력 유지. |
| 고대 성벽 브릭 | 공격력 2배, 고대종 맷집 추가, 고대의 저주 무효. 기존 6속성 맷집 유지. 체력 증가 없음. |

아쿠아마린의 기존 밀치기는 속성 제한이 없어 이미 무속성에도 적용됐다. 새로운 무속성 전용 배수나 맷집은 추가하지 않았다. 체력은 앞서 제안한 2배를 로컬 적용 기준으로 사용했다.

Lv.30·보물 완성 기준 체력/공격력은 아쿠아마린 402,500/44,275, 코발트 109,480/35,700, 브라운 116,685/7,400, 브릭 61,583/34,210이다. 브라운은 최초 연결 후 공격력을 50% 추가 상향했다. 실제 가격 표시는 장과 진화 가격 규칙의 영향을 받으므로 같은 조건의 2진과 비교한다.

## 연결과 저장

- `third-forms-87.js`: 능력, 진화 허용, 형태 선택, 저장 소유 복구, 애니메이션 선택, 강화 카드 설명.
- `reviews-third87.js`: 새 3진의 장점·단점·해금 조건을 도감 총평에 연결.
- `assets/third-form-87-motion/`: 네 명의 WebP 전투 시트와 PNG 프로필, 프레임 정보. idle 60장·walk 24장·attack 19~28장·hurt 24장, 30fps.
- `assets/third-form-87-parts/`: 승인된 투명 원본 파츠와 조립 모션 소스. 원본 PNG를 덮어 편집하지 않았다.
- 실제 넉백 이동·바운스는 기존 전투 엔진이 담당한다. 전투용 hurt 프레임에는 표정·자세만 내보내 중복 이동을 방지했다.
- 일반 3진과 같은 세계편 3장 달·Lv.20·개다래·XP 조건을 사용한다. 자동 지급하지 않는다. 기존 1·2진과 저장 키를 유지한다.
- 아쿠아마린은 예전 울슈레 코드의 3진 차단 및 진화 버튼 제거를 새 3진에 한해 보완했다. 늦게 등록되는 아쿠아마린의 저장된 3진 소유도 복구한다.
- 전투 시트는 PNG 원본 약 28MB에서 WebP 약 8.7MB로 줄였다. 무손실 원본 내보내기는 `work/third87-integration/raw-atlases/`에 보관한다.

## 확인

`node scripts/check-third87.cjs` 통과. 기존 1·2진 불변, 승인 능력치, 독 추가 피해 차단, 공따 무효, 저주 무효, 떠 있는 적 맷집, 전방위 앞뒤 범위 안팎, 형태 선택, 재료를 사용한 진화, 저장 소유 복원, 시트 파일·발밑 기준점을 확인했다.

실제 게임 HTML을 불러오는 임시 계정 화면에서 네 명의 에셋·공격·넉백, 강화 카드 설명과 1·2·3진 버튼, 미획득 아쿠아마린의 진화 버튼과 구매 후 전환을 확인했다. 임시 계정은 메모리 저장소를 사용해 사용자의 실제 진행도를 바꾸지 않는다.

범용·떠 있는 적·에이리언 시험 맵에서 2진/3진 덱을 각 60초 실행한 6조건에서 실행 예외는 없었다. 여섯 조건 모두 제한시간에 도달했으므로 클리어나 성능 우위를 입증한 결과는 아니다. 티어표와 전 맵 최강 덱은 재측정하지 않았다.

확인 화면과 상세 결과: `work/third87-integration/battle-preview.html`, `check.json`, `battle-smoke.json`, `battle-attack-final.png`, `battle-hurt-final.png`.
