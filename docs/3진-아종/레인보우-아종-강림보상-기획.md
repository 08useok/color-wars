# 레인보우 아종 — 허리케인 강림 보상

현재 등록된 사이클론 강림 8개를 게임 데이터로 확인했다. 보상 아종이 없는 강림은 **허리케인 사이클론의 긴급 폭풍 경보 / 진격의 폭풍 소용돌이** 한 곳이다. 나머지 7개 강림에는 보상 아종이 연결되어 있다.

사용자 확정: 이 강림의 보상은 **레인보우 아종**으로 만든다. 7.4 해양 탐사 콘텐츠보다 먼저 작업한다.

## 확정·연결

- 이름: **팽이 레인보우** → **자이로 레인보우**. 성별은 남성으로 확정했다.
- 외형: 무지개색 팽이 공연가. 1진은 단순한 둥근 몸과 팽이, 2진은 짧은 머리·뒤로 쓴 모자·공연복으로 구별한다.
- 역할: 짧은 사거리에서 빠른 연속 타격과 크리티컬로 메탈 무리를 상대하는 양산 딜러. 장거리에서 메탈 한 마리를 확실히 처치하는 응원단 민들레와 역할을 구별한다.
- 등급·획득: 레어, 강림 클리어 시 30% 확률.
- 초기 전투 설정: 사거리 6, 공격 주기 0.75초, 0.12/0.30/0.48초에 총 공격력의 1/3씩 범위 3연타, 크리티컬 15%·2배. 원본 레인보우의 속성 초데미지나 메탈 킬러는 물려받지 않는다.
- 출시 전 XP만 받고 클리어했던 계정은 기존 클리어 기록으로 보상을 한 번 복구하도록 설계한다. 이후 드롭 실패나 재시작으로 중복 지급되지 않아야 한다.

2026-10-30: 1·2진별 대기 4·걷기 4·공격/복귀 7·넉백 1, 총 32프레임을 기본 내장 imagegen 도구로 제작했다. 원본·프롬프트는 `reference-sheets/spintop-rainbow/`, 게임 시트·좌표는 `assets/spintop-rainbow-motion/`, 모션 미리보기는 `work/spintop-rainbow-motion/preview.html`에 있다.

`spintop-rainbow.js`로 아군·모션·프로필·강림 30% 드롭을 연결했다. 기존 클리어 계정은 최초 적용 때 1회 지급하며, 신규 계정의 드롭 실패가 재접속 지급으로 바뀌지 않도록 이관 표식을 기록한다. 재지급으로 플러스 레벨을 올리지 않는다. 허리케인의 첫/재도전 XP 3,800/1,900 기본값을 유지한다.

검증: 실제 3연타 분할 피해, 크리티컬/불발 메탈 피해, 기존 캐릭터·출현표 유지, 두 형태 출격·이미지, 보상 이전 클리어 지급·중복 방지·실패 후 재접속·레벨/형태 저장 복원을 확인했다. 직접 보상 처리 호출과 실제 전투 함수 검사를 구분했다. 사용자 저장은 바꾸지 않은 별도 브라우저 계정으로 확인했다.
