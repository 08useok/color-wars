# 베르디그리 3진 · 7.5 단독 신규 3진

사용자가 7.5 신규 3진 한 명으로 베르디그리를 선택했다. 현재 게임 분류는 슈퍼 레어이며 희귀도 변경은 요청받지 않았다.

## 확정한 강화 방향

- 3연속 공격.
- 2타는 1타보다 길고, 3타는 2타보다 길다. 이번 초안에서는 타격 사거리의 증가로 해석했다.
- 체력·공격력 증가.
- 공격 간격을 기존보다 0.5초 줄인다.
- 열파 추가.

기존 공격 간격은 2.2초이므로 3진은 **1.7초**다. '공속 0.5초 더 빨리'를 선딜 0.5초 감소로 해석하지 않는다.

## 수치 제안 · 아직 미확정

|항목|2진 현재|3진 제안|
|---|---:|---:|
|체력 배율|100%|150%(+50%)|
|직접 공격 한 주기 총 피해 배율|100%|150%(+50%), 세 타격으로 균등 분배|
|공격 간격|2.2초|1.7초|
|타격 시점|선딜 0.35초|0.35·0.65·0.95초|
|각 타격 도달 거리|7.2|7.2 → 12 → 18|
|공격 시작 거리|7.2|7.2 유지|
|공격 형태|개체|개체 3연타 유지|
|밀치기|45%·거리 18(보물 추가 효과 전)|3타에 기존 확률·거리로 배치하는 안|
|열파|없음|3타에만 발동, 앞쪽 8~30, 2초·0.5초 간격, 매 틱 3타 기본 피해의 50%|

현재 시험 도구 Lv.30·2진·기준 보물 상태의 체력 128,800·공격력 17,640을 기준으로 제안하면 3진 체력 193,200, 직접 한 주기 총 피해 26,460(각 8,820)이 된다. 실제 계정의 레벨·보물에 따라 달라지므로 이 값을 모든 계정에 고정하지 않는다.

밀치기를 3타에 모으자는 것은 제작상 제안이다. 첫 타격부터 기존 거리로 밀어내면 다음 타격이 빗나갈 수 있어, 1·2타로 연속 타격하고 3타에서 밀어내며 열파를 남기는 구성을 제안했다. 사용자가 명시한 확정 사항으로 기록하지 않는다. 열파가 매 타격마다 세 번 발생하는 방식도 아직 확정하지 않았다.

열파 피해는 세 타격 총 공격력이 아니라 마지막 타격에 배분된 피해를 기준으로 한다. 공용 `strike-hits.js`는 타격별 `abilities.range/zoneMax` 등 임시 수치를 지원하지만 `launchSurge`는 자체적으로 직접 피해 비율을 곱하지 않으므로 구현 시 열파 피해 비율을 별도로 검증해야 한다.

가격·생산 시간·이동속도·히트백 변경은 현재 계획하지 않는다. 공체 배율·타격별 거리·열파 범위와 피해·밀치기 타격 배치는 제안이며 추가 확정 전이다.

## 제작·검증 상태

이번에는 기획만 저장했다. 3진 전용 외형·모션·게임 능력치·개다래 해금·총평·티어는 아직 적용하지 않았다. 전용 3진 에셋이 없는 상태에서 기존 출시 잠금을 해제하지 않는다. 구현 시 같은 적에 대한 거리별 3회 적중, 밀치기 뒤 후속 타격, 열파 발동 횟수·틱 피해, 2진 능력치 불변을 검증한다.

## 2026-10-31 적용 완료

사용자의 “해. 그림도 3진 반영”에 따라 위 수치 제안을 승인된 제작안으로 적용했다.

- 이름: **터빈 베르디그리**. 기존 청록색 정비 로봇을 바탕으로 구리 테두리 장갑·터빈·신축 스패너 팔을 추가했다.
- 체력/한 주기 직접 피해 각각 150%, 간격 1.7초, 개체 3연타(0.35/0.65/0.95초), 도달 거리 7.2/12/18. 공격 시작 거리 7.2 유지.
- 마지막 타격만 기존 밀치기. 마지막 타격 열파는 8~30, 2초 동안 총 4틱, 틱마다 마지막 타격 기본 피해의 50%. 직접 3타 합계와 열파 피해를 중복 배율 없이 검증했다.
- 전용 투명 시트 16프레임: 대기 4, 걷기 4, 공격 7, 넉백 1. 타격 프레임은 실제 0.35/0.65/0.95초와 동기화했다.
- 기존 세계편 3장·Lv.30 해금과 슈퍼 레어 개다래 비용 사용. 가격·생산 시간·이속·히트백·기존 1/2진 불변.
- 전투·도감 총평·3진 전용 프로필 연결. 티어 재측정과 버전 변경·커밋·푸시는 하지 않았다.

검증: `scripts/test-verdigris-third.cjs` 통과(전체 아군 미진화 상태 불변, 1/2진 불변, 거리별 적중, 예약된 3타, 마지막 타격 열파 4틱). 브라우저 독립 시험 계정에서 진화 비용 열매3/씨앗5/XP100,000 차감, 중복 진화 방지, 실제 타격 3회·열파1개·전용 시트 1536×1024 디코딩·총평·새로고침 유지 확인. 사용자 계정 저장에는 접근하지 않았다.

- 제작: 내장 이미지 생성 도구. 원본/프롬프트 `reference-sheets/verdigris-3-motion/`.
- 게임 에셋: `assets/verdigris-3-motion/`.
- 모션 미리보기: `work/verdigris-3-motion/preview.html`.
- 증거: 같은 폴더의 `combat-validation.json`, `browser-validation.json`, `audit.json`.

## 외형 2차 수정

본체 표시 높이를 기존 180px에서 약 198px로 확대하고 작은 바퀴형 청록색 보조 로봇 한 대를 모든 16프레임에 추가했다. 새 에셋은 `assets/verdigris-3-motion-v2/`에 저장해 이전 그림을 보존했다. 도감 프로필과 전투 시트 모두 새 그림을 사용하며 기존 미리보기 주소도 갱신했다. 공체·공속·3연타·열파 수치는 그대로다. 전투 검사 재통과, 투명 알파·16프레임 잘림 없음 검사 통과.
