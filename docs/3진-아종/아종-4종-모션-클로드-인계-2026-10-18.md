# 아종 4종 모션 — 클로드 인계

## 완료 범위

승인된 PNG 초안을 바탕으로 내장 image_gen에서 실제 자세가 다른 모션 원화를 생성했다. 캐릭터 4명 × 1·2진, 총 8형태. 각 형태는 걷기 4, 공격 6, 피격 1, 피격 회복 1 = 12개 자세이며 총 96개다. 투명 배경의 WebP 아틀라스 8개와 256px 초상화 8개를 게임에 연결했다.

3진은 여전히 전용 아트가 없어 잠긴다. 능력치·가격·생산·공격 주기·판정은 이번 모션 작업에서 바꾸지 않았다.

## 게임 연결

`red-battle-doge.html`에서 다음 순서로 읽는다.

1. 기존 `cyclone-motion-atlases.js` / `cyclone-advents.js`: 아군 등록 및 기존 임시 강림 코드.
2. 신규 `subspecies-motion-atlases.js`: `SUBSPECIES_MOTION_ATLASES` 메타데이터.
3. 신규 `subspecies-motion.js`: 4명에 한해서 `NEW_ATLASES[id]`·`PROFILE_ART[id]`를 승인 초안의 래스터 이미지로 바꾼다. 프로필 성별도 명시한다. 피격 후반부는 회복 자세를 선택한다.
4. 기존 `asset-loader.js`.

캐릭터 등록을 이중으로 하지 말 것. 1진/2진 모션은 `NEW_ATLASES[id]` / `NEW_ATLASES[id].evolved`. 프레임은 `[x,y,w,h,ox,oy]`, 표시 scale .5, groundAnchor 사용. 공격 선딜 .3초 시점에 strike=2를 맞춰 6프레임을 재생한다. 모든 형태가 왼쪽을 보므로 아군을 추가로 반전하면 안 된다.

클로드가 아군 등록을 별도 파일로 분리한다면 위 2·3번을 등록 뒤, 이미지 로더 앞에 유지한다. `CYCLONE_ALLIES`의 4개 ID와 기존 소유·훈련 저장 형식을 유지한다.

## 사이클론 스테이지 작업 범위

이번에는 스테이지/보스/보상 코드를 수정하지 않았다. **이전 작업에서 만든 임시 사이클론 4개와 맵·보상 연결이 `cyclone-advents.js`에 이미 존재한다.** 완성된 원본 위키 반영본으로 간주하지 말고, 클로드가 위키 기준으로 재검토·교체할 대상이다. 같은 맵을 새로 덧붙여 중복 등록하지 않도록 확인한다. 기존 맵 번호·세이브 호환을 보존한다.

유저가 사이클론 스테이지 제작은 클로드에게 맡길 예정이라고 했다. 이 문서는 인계 자료이며 다른 채팅에 메시지를 보내지 않았다. 이번 작업에 커밋·푸시 요청은 없었다.
