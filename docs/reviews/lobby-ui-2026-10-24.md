# 로비 캐릭터 관리·전투 진입 개선

소스: lobby-navigation.js, lobby-navigation.css, red-battle-doge.html의 연결 태그 2개. 기존 전투 함수·수치·보물 계산·저장 형식·보상 수령 함수는 변경하지 않는다. 기존 renderTraining을 선택한 캐릭터 1명만 렌더하도록 감싸며, 기존 강화·덱·진화 버튼과 후속 확장 코드를 계속 사용한다.

- 전투 선택을 랭크·뽑기·강화보다 앞으로 이동. 장·레전드 왕관·스테이지·소탕 기능 유지. 선택한 장의 다음 미클리어를 실제 전투로 바로 연다. 미클리어가 없으면 비활성화.
- 캐릭터 검색(이름·역할), 등급, 보유/현재 덱/강화 가능 보기. 12명씩 간단 선택 버튼과 선택한 1명 상세 카드. 빈 검색 결과와 페이지 경계를 처리한다. 캐릭터 바로가기는 검색에 포커스를 준다.
- 현재 콘텐츠에 맞는 큰 제목·부제. 레전드 전설의 시작 ★4의 진행도를 동일 맥락으로 표시한다.
- 기지 Lv.30과 2·3장 클리어별 상한 설명. 최대 레벨 카드·보물 설명과 스페셜을 접어 핵심 동선을 줄인다.
- 우주편은 클리어 2/2장과 실제 보물 효과 1장분을 분리해 표시. 2장 빅뱅은 추가 XP/특성 보물 배율을 주지 않으며 가면·억제기가 장별 처리됨을 명시한다. 보물 함수를 수정하지 않는다.
- 뽑기 버튼에 보유 확정권/미수령을 명시하고 보관함 바로가기를 제공한다. 이동만으로 116장을 수령하지 않는다.
- 기존 남색 디자인의 버튼, 키보드 포커스, 불투명 로비 배경. 전투 화면 뒤비침을 제거한다.
