# 도감 총평·능력치 기준 통일 검증 (2026-10-24)

## 범위

대상은 레드 · 세계편이다. COLORS 프로젝트가 아니다. 게임 밸런스·능력치·레벨·보물 효과·저장 형식은 변경하지 않았다. 새 codex-review-consistency.js/.css를 기존 총평·서열 생성 스크립트 뒤, 형태 선택 wrapper 앞에 연결했다. 기존 정적 총평 자료를 직접 전투 수치로 사용하지 않으며 현재 도감 경로에서는 공통 동적 총평으로 대체한다.

## 원인과 기준

기존 표는 game.js의 unitStats(type, evolved ? 10 : 1, 2)였다. progression.js에서 기본 인자에 계정의 +레벨을 더하므로 실제 표는 1진 Lv.1+추가레벨, 2진 Lv.10+추가레벨이었다. 총평은 codexReviewStats가 +레벨을 빼 합산 Lv.30으로 고정했으며 현재 세계편 보물 배율을 포함했다. 서로 다른 기준과 오래된 하드코딩 문장이 섞여 있었다.

관찰값 재현: 레드 2진 Lv.13(10+3)은 체력 9,968·공격력 515, 플래티넘 1진 Lv.1은 체력 6,698이다. 해당 관찰값 자체가 잘못 계산된 것은 아니지만, 같은 화면에 Lv.30 총평과 같이 놓이고 기준이 명확하지 않았다. 레인보우 총평의 사거리 50은 현재 원본 사거리 30과 실제로 충돌하는 오래된 문장이었다.

새 기준은 표와 총평 모두 합산 Lv.30(기본+추가 합계 고정), 선택한 형태, 현재 계정 보물, 세계편 2·3장 가격이다. 실제 계정 레벨은 바꾸지 않는다. 덱 콤보·전투 중 강화는 제외한다. 현재 보물 완료 장 수와 게임 내 거리 단위를 안내한다. 계정별 보물 차이는 표시값에 반영한다.

## 피해 표시

- 직접 타격만 비교한다. 같은 대상에게 방해 없이 직접 타격을 모두 맞히는 이론값이다. 파동·열파 추가 피해는 제외하고 별도 능력 설명으로 제공한다. 부메랑은 왕복 모두 적중, 거리별 피해는 도달 가능한 최고 구간, 관통은 첫 대상 조건을 명시한다.
- 크리티컬·혼신의 일격은 확률 기대값을 반영한다. 실제 엔진의 범위/관통/연타 분기와 크리스프·3진 코랄의 전용 타격별 배분도 반영한다.
- 실제 damage는 속성 배율·크리티컬을 계산한 뒤 비크리티컬 메탈 피해를 1로 제한한다. 따라서 레인보우의 메탈 초데미지 배율상 46,666.67을 실효 DPS처럼 표시할 수 없다. 4초마다 일반 타격 1이므로 메탈 직접 DPS는 0.25다. 에이리언 상대 46,666.67 등 실제로 적용되는 속성 수치는 별도로 표시한다.
- 메탈 킬러는 비크리티컬 시 1 + ceil(대상 현재 체력 × 비율)이다. 고정 DPS를 만들지 않고 체력 의존임을 표시한다. 무속성과 성만 공격하는 캐릭터는 메탈 DPS를 적용하지 않는다.
- 베리어, 적의 피해 감소, 표식, 보스 특효, 분노, 체력 조건 강화 및 넉백·위치 이탈로 잃는 피해는 이론값과 구분한다. 총평에 계산 조건을 명시한다.

## 문장 정리

모든 캐릭터에 강점·구체적 약점·편성 판단을 한 번씩만 표시한다. 뒤에 같은 설명을 반복하던 평가 문단은 추가하지 않는다. 검증 조건이 불명확한 티어·상하위권·최고/최악 문구도 새 총평에는 주입하지 않는다. 캐릭터별 효과·대상 속성·확률·지속시간·비용·선딜·재출격을 현재 stats에서 읽는다.

아이언의 좀비 킬러를 현재 좀비 침공·좀비 등장 스테이지와 연결하고, 직접 마무리해야 부활을 막는 조건을 명시했다. 플래티넘은 기본 50% 확률·3초 느리게를 자연스럽게 표현하고 이동 제어와 공격 정지를 구분했다. 지속시간에는 대상 보물 보정이 추가될 수 있음을 안내한다. 레인보우는 일반 범위 타격과 빨강·떠있음·메탈·검정·천사·에일 초데미지 대상 목록을 분리해 무속성·좀비까지 모든 적 특효로 오해하지 않게 했다.

## 검증

- Node: 115명, 보물 없음 230형태 + 보물 완료 242형태 = 472형태/조건. 해금되지 않는 3진을 보물 없는 조건의 가짜 출시 형태로 세지 않았다.
- 실제 resolveAttack/damage와 3,743개 속성·형태별 직접 피해 기대값을 비교했다. 크리티컬/비크리티컬과 혼신의 일격 분기를 강제로 분리한 격리 시험 뒤 확률로 합산했다. 전투 코드 자체를 바꾸거나 실제 계정 수치를 조작하지 않았다.
- 메탈 킬러는 별도 실제 피해 경로에서 1 + ceil(현재체력×비율)을 확인했다. +레벨 0/10에서도 합산 Lv.30 표시가 동일하고, selectedStage·training·cleared·trueForms·progression이 계산 전후 동일함을 확인했다.
- Ego: 현재 해금 가능한 242형태 전부 표·총평의 체력/공격력/사거리/공격 주기/재출격/비용이 일치. 총평 한 개, 중복 평가 없음, 오래된 좀비 부재·사거리 50·임의 서열 문구 없음. 오류 0건.
- 관찰한 5명 사례 확인 및 실제 형태 선택 버튼으로 살몬 2진/3진 전환. 보유 진화·레벨·덱·클리어 상태 보존. 별도 localStorage 전후 전체 키/값 비교도 동일했다.
- 데스크톱 1440px와 모바일 390px 확인. 모바일 도감 패널 350px/스크롤 폭 350px. 캡처는 work/codex-consistency-qa-20261024/에 있다.

정적/계산 시험: node scripts/test-codex-review-consistency.cjs.
브라우저 재검증: node scripts/serve-lobby-ui-qa.cjs를 별도로 열고 Ego에서 scripts/test-codex-review-consistency-ego.mjs를 실행한다. 이 검증 서버는 localhost 격리 계정에서만 fixture를 주입하며 배포 코드에는 검증용 접근을 추가하지 않는다.

기록: codex-consistency-verification-2026-10-24.json, codex-consistency-browser-2026-10-24.json, codex-consistency-examples-2026-10-24.json, codex-storage-check-2026-10-24.json.
