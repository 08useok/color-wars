# 아군 티어표 · 9개 시험 맵 종합 (2026-10-30)

현재 기준은 범용·빨간 적·검은 적·천사·에이리언·떠 있는 적·메탈·좀비·파동 시험 각 1/9이다. **144개 형태: 비교 가능한 140개 + 기준덱 멤버 4개 별도 참고.** 라일락·베이비 핑크·마젠타·퓨전 크림 3진은 공체 150%를 반영해 216판 재측정했고, 기준덱 54판이 이전 결과와 정확히 일치함을 확인했다. 나머지는 앞선 전체 7,992판 결과를 재사용했다.

Lv.30·보물 완성·시드 3·auto/smart2 중 시드별 높은 결과. 후보를 기준덱(레드·옐로우·블루·퍼플)에 한 칸 추가한 이득의 맵별 백분위를 평균한다. 승리 점수는 `2-초/300`, 패배·시간 초과는 모두 0이다. 실패 사이의 진행도 차이는 반영하지 않는 **1차 종합 티어**이며 전체 맵의 보편적 성능을 뜻하지 않는다.

경계는 기존 백분위 체계(OP .90 / SSS .79 / SS .72 / S .60 / A .50 / B .40 / C .30 / D .22 / E .15 / F .08)를 유지해 새 맵 도입과 임의 구간 재분배를 섞지 않았다. OP 이외는 구간 안 상위·하위 1/3에 +/−를 붙이고 같은 점수는 같은 표기를 쓴다. 구간 인원이 3명 미만이면 부호를 붙이지 않는다. X는 낮은 점수만으로 지정하지 않고 특화 가치까지 없는지 별도 확인하므로 이번 자동 판정에서는 보류한다.

기준덱 네 명은 본인을 뺀 덱과 비교해 기준이 다르므로 **† 참고 티어**, 전체 순위와 +/−에서는 제외한다. 순위 차이보다 비슷한 점수와 속성별 결과를 함께 보는 것이 좋다.
